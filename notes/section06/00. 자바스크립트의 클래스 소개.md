# Section 6 - 0. 자바스크립트의 클래스 소개

**1. 클래스란?**

클래스는 **같은 구조의 객체를 반복해서 만들기 위한 문법**이다.

객체를 직접 만들면:

```js
const studentA = {
  name: "홍길동",
  grade: "A+",
  age: 27,
};

const studentB = {
  name: "김철수",
  grade: "B+",
  age: 25,
};
```

구조는 같고 값만 다르다.

이런 객체가 많아지면 같은 코드를 계속 반복해야 하므로 클래스를 사용한다.

```text
클래스
→ 객체를 만드는 틀

객체
→ 클래스로 만들어진 실제 값
```

---

**2. 클래스 선언하기**

`class` 키워드로 선언한다.

```js
class Student {}
```

클래스 이름은 보통 첫 글자를 대문자로 작성한다.

---

**3. 필드**

필드는 클래스가 생성할 객체가 가지는 프로퍼티이다.

```js
class Student {
  name;
  grade;
  age;
}
```

이 클래스로 만든 객체는 다음 프로퍼티를 가진다.

```text
name
grade
age
```

---

**4. constructor**

`constructor`는 객체를 생성할 때 초기값을 설정하는 특별한 메서드이다.

```js
class Student {
  name;
  grade;
  age;

  constructor(name, grade, age) {
    this.name = name;
    this.grade = grade;
    this.age = age;
  }
}
```

생성자에 전달된 값을 객체의 프로퍼티에 저장한다.

```text
매개변수
↓
constructor
↓
this의 프로퍼티에 저장
```

---

**5. this**

클래스 메서드 안에서 `this`는 **현재 메서드를 호출한 인스턴스 객체**를 가리킨다.

```js
this.name
this.grade
this.age
```

생성자에서는 새로 만들어지는 객체를 가리킨다.

```js
this.name = name;
```

즉, 현재 생성 중인 객체의 `name`에 값을 저장한다.

---

**6. new로 객체 생성하기**

클래스에서 객체를 만들 때는 `new`를 사용한다.

```js
const student = new Student(
  "홍길동",
  "A+",
  27
);
```

실행 흐름:

```text
new Student(...)
↓
constructor 실행
↓
전달받은 값으로 필드 초기화
↓
Student 객체 생성
```

생성된 객체는 다음과 같은 값을 가진다.

```text
name: "홍길동"
grade: "A+"
age: 27
```

---

**7. 클래스 메서드**

클래스에는 객체가 사용할 메서드도 정의할 수 있다.

```js
class Student {
  name;
  grade;
  age;

  constructor(name, grade, age) {
    this.name = name;
    this.grade = grade;
    this.age = age;
  }

  study() {
    console.log("열심히 공부함");
  }

  introduce() {
    console.log(`안녕하세요 ${this.name}입니다.`);
  }
}
```

사용:

```js
const student = new Student(
  "홍길동",
  "A+",
  27
);

student.study();
student.introduce();
```

메서드에서는 `this`를 이용해 현재 객체의 프로퍼티에 접근할 수 있다.

---

**8. 상속**

기존 클래스를 기반으로 새로운 클래스를 만들 수 있다.

이를 **상속**이라고 한다.

```js
class StudentDeveloper extends Student {}
```

```text
Student
   ↑
StudentDeveloper
```

`StudentDeveloper`는 `Student`의 필드와 메서드를 사용할 수 있다.

```text
Student에서 상속

name
grade
age
study()
introduce()
```

---

**9. 자식 클래스에 기능 추가하기**

상속받은 클래스에 새로운 필드와 메서드를 추가할 수 있다.

```js
class StudentDeveloper extends Student {
  favoriteSkill;

  programming() {
    console.log(
      `${this.favoriteSkill}로 프로그래밍함`
    );
  }
}
```

`StudentDeveloper`는 부모의 기능과 자신의 기능을 모두 가진다.

```text
상속받은 기능
+
favoriteSkill
programming()
```

---

**10. super**

자식 클래스에서 생성자를 직접 작성하면 부모 클래스의 생성자를 `super()`로 호출해야 한다.

```js
class StudentDeveloper extends Student {
  favoriteSkill;

  constructor(
    name,
    grade,
    age,
    favoriteSkill
  ) {
    super(name, grade, age);
    this.favoriteSkill = favoriteSkill;
  }
}
```

실행 흐름:

```text
StudentDeveloper 생성
↓
super(name, grade, age)
↓
Student constructor 실행
↓
name, grade, age 초기화
↓
favoriteSkill 초기화
```

파생 클래스의 생성자에서 `this`를 사용하기 전에 `super()`를 먼저 호출해야 한다.

---

**11. 상속받은 객체 사용하기**

```js
const studentDeveloper =
  new StudentDeveloper(
    "홍길동",
    "B+",
    27,
    "TypeScript"
  );
```

사용 가능한 프로퍼티:

```text
name
grade
age
favoriteSkill
```

사용 가능한 메서드:

```js
studentDeveloper.study();
studentDeveloper.introduce();
studentDeveloper.programming();
```

부모에게서 상속받은 기능과 자식이 추가한 기능을 모두 사용할 수 있다.

---

**12. 전체 코드**

```js
class Student {
  name;
  grade;
  age;

  constructor(name, grade, age) {
    this.name = name;
    this.grade = grade;
    this.age = age;
  }

  study() {
    console.log("열심히 공부함");
  }

  introduce() {
    console.log(
      `안녕하세요 ${this.name}입니다.`
    );
  }
}

class StudentDeveloper extends Student {
  favoriteSkill;

  constructor(
    name,
    grade,
    age,
    favoriteSkill
  ) {
    super(name, grade, age);
    this.favoriteSkill = favoriteSkill;
  }

  programming() {
    console.log(
      `${this.favoriteSkill}로 프로그래밍함`
    );
  }
}

const studentDeveloper =
  new StudentDeveloper(
    "홍길동",
    "B+",
    27,
    "TypeScript"
  );

studentDeveloper.study();
studentDeveloper.introduce();
studentDeveloper.programming();
```

---

**13. 핵심 정리**

* 클래스는 같은 구조의 객체를 반복해서 만들기 위한 문법이다.
* `class` 키워드로 선언한다.
* 필드는 인스턴스가 가지는 프로퍼티이다.
* `constructor`는 객체 생성 시 초기값을 설정한다.
* `new 클래스이름()`으로 객체를 생성한다.
* 클래스 메서드에서는 `this`로 현재 인스턴스에 접근할 수 있다.
* `extends`를 사용하면 기존 클래스를 상속할 수 있다.
* 자식 클래스는 부모 클래스의 필드와 메서드를 사용할 수 있다.
* 자식 클래스에는 새로운 필드와 메서드를 추가할 수 있다.
* 자식 클래스의 생성자에서는 `super()`로 부모 생성자를 호출한다.
* 핵심은 **`class = 객체 생성 구조`, `extends = 기존 클래스 재사용`, `super = 부모 생성자 호출`**이다.
