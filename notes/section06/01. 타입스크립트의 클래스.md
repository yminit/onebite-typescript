# Section 6 - 1. 타입스크립트의 클래스

**1. 클래스 필드에 타입 지정하기**

TypeScript 클래스에서는 필드에 타입을 지정할 수 있다.

```ts
class Employee {
  name: string;
  age: number;
  position: string;
}
```

각 필드는 다음 타입을 가진다.

```text
name → string
age → number
position → string
```

---

**2. 필드는 초기화가 필요하다**

필드를 선언했다면 값을 초기화해야 한다.

방법은 두 가지다.

a. 선언과 동시에 초기화

```ts
class Employee {
  name: string = "";
  age: number = 0;
  position: string = "";
}
```

b. 생성자에서 초기화

```ts
class Employee {
  name: string;
  age: number;
  position: string;

  constructor(
    name: string,
    age: number,
    position: string
  ) {
    this.name = name;
    this.age = age;
    this.position = position;
  }
}
```

실무에서는 생성할 때 값을 전달받아야 한다면 보통 생성자에서 초기화한다.

---

**3. 생성자 매개변수에도 타입 지정하기**

```ts
constructor(
  name: string,
  age: number,
  position: string
) {
  this.name = name;
  this.age = age;
  this.position = position;
}
```

클래스를 생성할 때 전달하는 값도 이 타입을 따라야 한다.

```ts
const employee = new Employee(
  "이정환",
  27,
  "developer"
);
```

잘못된 타입을 전달하면 오류가 발생한다.

---

**4. 선택적 필드**

필드 이름 뒤에 `?`를 붙이면 선택적 프로퍼티가 된다.

```ts
class Employee {
  name: string;
  age?: number;
  position: string;

  constructor(
    name: string,
    position: string
  ) {
    this.name = name;
    this.position = position;
  }
}
```

`age`는 사실상 다음 타입을 가진다.

```text
number | undefined
```

따라서 사용할 때 `undefined` 가능성을 고려해야 한다.

---

**5. 클래스는 타입으로도 사용할 수 있다**

TypeScript에서 클래스는 객체를 만드는 값이면서 동시에 타입으로 사용할 수 있다.

```ts
class Employee {
  name: string;
  age: number;
  position: string;

  constructor(
    name: string,
    age: number,
    position: string
  ) {
    this.name = name;
    this.age = age;
    this.position = position;
  }

  work() {
    console.log("일함");
  }
}
```

다음처럼 사용할 수 있다.

```ts
const employee: Employee = new Employee(
  "이정환",
  27,
  "developer"
);
```

---

**6. 클래스 타입도 구조를 기준으로 판단한다**

TypeScript는 구조적 타입 시스템을 사용하므로 클래스 타입도 구조를 기준으로 판단한다.

```ts
const employee: Employee = {
  name: "이정환",
  age: 27,
  position: "developer",

  work() {
    console.log("일함");
  },
};
```

`Employee` 인스턴스가 아니더라도 필요한 구조를 모두 가지고 있다면 호환될 수 있다.

즉, `Employee` 타입은 대략 다음 구조를 요구한다.

```text
name: string
age: number
position: string
work(): void
```

---

**7. 클래스 상속**

JavaScript와 마찬가지로 `extends`를 사용한다.

```ts
class ExecutiveOfficer extends Employee {
  officeNumber: number;
}
```

```text
Employee
   ↑
ExecutiveOfficer
```

`ExecutiveOfficer`는 `Employee`의 필드와 메서드를 물려받는다.

---

**8. 파생 클래스의 생성자**

파생 클래스에서 생성자를 직접 만들면 부모 생성자를 `super()`로 호출해야 한다.

```ts
class ExecutiveOfficer extends Employee {
  officeNumber: number;

  constructor(
    name: string,
    age: number,
    position: string,
    officeNumber: number
  ) {
    super(name, age, position);

    this.officeNumber = officeNumber;
  }
}
```

`super()`가 부모 클래스의 필드를 초기화한다.

```text
super(...)
↓
Employee constructor 실행
↓
name, age, position 초기화
```

그 후 자식 클래스의 필드를 초기화한다.

```ts
this.officeNumber = officeNumber;
```

---

**9. super와 this의 순서**

파생 클래스 생성자에서는 `this`를 사용하기 전에 `super()`가 실행되어야 한다.

```ts
constructor(
  name: string,
  age: number,
  position: string,
  officeNumber: number
) {
  super(name, age, position);

  this.officeNumber = officeNumber;
}
```

흐름:

```text
파생 클래스 생성자 실행
↓
super()
↓
부모 클래스 초기화
↓
this 사용 가능
↓
자식 클래스 필드 초기화
```

**10. 전체 코드**

```ts
class Employee {
  name: string;
  age: number;
  position: string;

  constructor(
    name: string,
    age: number,
    position: string
  ) {
    this.name = name;
    this.age = age;
    this.position = position;
  }

  work() {
    console.log("일함");
  }
}

class ExecutiveOfficer extends Employee {
  officeNumber: number;

  constructor(
    name: string,
    age: number,
    position: string,
    officeNumber: number
  ) {
    super(name, age, position);

    this.officeNumber = officeNumber;
  }
}

const employee = new Employee(
  "이정환",
  27,
  "developer"
);

const executiveOfficer = new ExecutiveOfficer(
  "홍길동",
  40,
  "CTO",
  101
);
```

---

**11. 핵심 정리**

* TypeScript 클래스의 필드에는 타입을 지정할 수 있다.
* 필드는 선언 시 초기화하거나 생성자에서 초기화해야 한다.
* 생성자 매개변수에도 타입을 지정한다.
* `?`를 붙이면 선택적 필드를 만들 수 있다.
* 클래스는 객체를 만드는 값이면서 동시에 타입으로 사용할 수 있다.
* 클래스 타입도 객체의 구조를 기준으로 호환성을 판단한다.
* `extends`를 사용하면 클래스를 상속할 수 있다.
* 파생 클래스의 생성자에서는 `super()`로 부모 생성자를 호출한다.
* `this`를 사용하기 전에 `super()`가 먼저 실행되어야 한다.
* 핵심은 **`TypeScript 클래스 = JavaScript 클래스 + 필드·생성자·인스턴스에 대한 타입 검사`**이다.
