# Section 6 - 2. 접근 제어자

**1. 접근 제어자란?**

접근 제어자(Access Modifier)는 클래스의 필드나 메서드에 **어디까지 접근할 수 있는지 제한하는 문법**이다.

TypeScript에서는 세 가지를 주로 사용한다.

```text id="accmod1"
public
→ 어디서든 접근 가능

private
→ 해당 클래스 내부에서만 접근 가능

protected
→ 해당 클래스 + 파생 클래스 내부에서 접근 가능
```

---

**2. public**

`public`은 가장 넓은 접근 범위를 가진다.

```ts id="pub001"
class Employee {
  public name: string;
  public age: number;
  public position: string;

  constructor(
    name: string,
    age: number,
    position: string
  ) {
    this.name = name;
    this.age = age;
    this.position = position;
  }
}
```

클래스 외부에서도 접근할 수 있다.

```ts id="pub002"
const employee = new Employee(
  "이정환",
  27,
  "developer"
);

employee.name;
employee.age;
employee.position;
```

접근 제어자를 생략하면 기본적으로 `public`으로 처리된다.

---

**3. private**

`private`은 **해당 클래스 내부에서만 접근할 수 있다.**

```ts id="pri001"
class Employee {
  private name: string;
  public age: number;
  public position: string;

  constructor(
    name: string,
    age: number,
    position: string
  ) {
    this.name = name;
    this.age = age;
    this.position = position;
  }

  work() {
    console.log(`${this.name}이 일합니다.`);
  }
}
```

클래스 내부에서는 사용할 수 있다.

```ts id="pri002"
this.name;
```

하지만 외부에서는 접근할 수 없다.

```ts id="pri003"
employee.name;
```

---

**4. protected**

`protected`는 클래스 내부와 **상속받은 파생 클래스 내부**에서 사용할 수 있다.

```ts id="pro001"
class Employee {
  private name: string;
  protected age: number;
  public position: string;

  constructor(
    name: string,
    age: number,
    position: string
  ) {
    this.name = name;
    this.age = age;
    this.position = position;
  }
}
```

파생 클래스:

```ts id="pro002"
class ExecutiveOfficer extends Employee {
  func() {
    // this.name; // private → 접근 불가

    this.age;      // protected → 접근 가능
    this.position; // public → 접근 가능
  }
}
```

---

**5. 접근 범위 정리**

```text id="scope001"
              클래스 내부   파생 클래스   클래스 외부

public            O            O            O

protected         O            O            X

private           O            X            X
```

핵심은 다음과 같다.

```text id="scope002"
public
→ 완전히 공개

protected
→ 상속 관계까지만 공개

private
→ 자기 클래스 내부만 공개
```

---

**6. protected는 외부에서 접근할 수 없다**

```ts id="pro003"
const employee = new Employee(
  "이정환",
  27,
  "developer"
);

employee.age;
```

`age`가 `protected`라면 클래스 외부에서는 접근할 수 없다.

`protected`는 `public`과 달리 외부 공개용이 아니다.

---

**7. 생성자 매개변수에 접근 제어자 사용하기**

TypeScript에서는 생성자 매개변수 앞에 접근 제어자를 붙일 수 있다.

```ts id="param001"
class Employee {
  constructor(
    public name: string,
    protected age: number,
    public position: string
  ) {}
}
```

이 문법을 사용하면 TypeScript가 같은 이름의 필드를 자동으로 만들어 준다.

즉, 다음 작업이 함께 처리된다.

```text id="param002"
매개변수 선언
+
필드 선언
+
필드 초기화
```

---

**8. 일반 방식과 비교**

일반적인 방식:

```ts id="compare001"
class Employee {
  public name: string;
  protected age: number;
  public position: string;

  constructor(
    name: string,
    age: number,
    position: string
  ) {
    this.name = name;
    this.age = age;
    this.position = position;
  }
}
```

생성자 매개변수에 접근 제어자를 사용하면:

```ts id="compare002"
class Employee {
  constructor(
    public name: string,
    protected age: number,
    public position: string
  ) {}
}
```

결과적으로 같은 필드를 만들지만 코드가 훨씬 짧아진다.

---

**9. 필드를 중복 선언하면 안 된다**

생성자 매개변수에 접근 제어자를 사용하면 이미 필드가 생성된다.

따라서 다음처럼 다시 선언하면 안 된다.

```ts id="dup001"
class Employee {
  name: string;

  constructor(
    public name: string
  ) {}
}
```

`name` 필드가 중복되기 때문이다.

둘 중 하나의 방식만 사용해야 한다.

---

**10. private와 JavaScript #private는 다르다**

TypeScript의 `private`은 주로 **타입 검사 단계에서 접근을 제한하는 기능**이다.

```ts id="privdiff1"
class Employee {
  private name: string;

  constructor(name: string) {
    this.name = name;
  }
}
```

JavaScript에는 별도로 `#`을 사용하는 private 필드 문법도 있다.

```js id="privdiff2"
class Employee {
  #name;

  constructor(name) {
    this.#name = name;
  }
}
```

둘은 비슷한 목적을 가지지만 같은 문법은 아니다.

현재 단계에서는 TypeScript의 `public`, `private`, `protected` 접근 범위를 정확히 이해하는 것이 중요하다.

---

**11. 전체 코드**

```ts id="all001"
class Employee {
  constructor(
    private name: string,
    protected age: number,
    public position: string
  ) {}

  work() {
    console.log(`${this.name}이 일합니다.`);
  }
}

class ExecutiveOfficer extends Employee {
  func() {
    // private이므로 접근 불가
    // this.name;

    // protected이므로 접근 가능
    this.age;

    // public이므로 접근 가능
    this.position;
  }
}

const employee = new Employee(
  "이정환",
  27,
  "developer"
);

// private
// employee.name;

// protected
// employee.age;

// public
employee.position;
```

---

**12. 핵심 정리**

* 접근 제어자는 클래스 멤버의 접근 범위를 제한한다.
* `public`은 어디서든 접근할 수 있다.
* 접근 제어자를 생략하면 기본적으로 `public`이다.
* `private`은 해당 클래스 내부에서만 접근할 수 있다.
* `protected`는 해당 클래스와 파생 클래스 내부에서 접근할 수 있다.
* `protected`와 `private` 모두 클래스 외부에서는 접근할 수 없다.
* 생성자 매개변수에 접근 제어자를 붙이면 필드 선언과 초기화를 한 번에 처리할 수 있다.
* 이 방식을 사용할 때 같은 이름의 필드를 따로 다시 선언하면 안 된다.
* 핵심은 **`public = 전체 공개`, `protected = 상속 관계까지`, `private = 자기 클래스 내부만`**으로 기억하면 된다.
