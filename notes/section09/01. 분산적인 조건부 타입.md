# Section 9 - 1. 분산적인 조건부 타입

**1. 분산적인 조건부 타입이란?**

조건부 타입의 타입 변수에 Union 타입이 들어오면, Union 전체를 한 번에 검사하지 않고 **각 멤버에 조건부 타입을 각각 적용한 뒤 다시 Union으로 합친다.**

```ts
type StringNumberSwitch<T> =
  T extends number
    ? string
    : number;
```

예:

```ts
type Result =
  StringNumberSwitch<number | string>;
```

결과:

```ts
string | number
```

---

**2. 왜 number만 나오지 않을까?**

겉으로 보면 다음처럼 생각하기 쉽다.

```ts
number | string extends number
  ? string
  : number
```

`number | string` 전체는 `number`에 할당할 수 없으므로 `number`가 될 것처럼 보인다.

하지만 실제로는 Union이 분산된다.

```text
number | string
↓
number
string
↓
각각 조건 검사
↓
결과를 다시 Union으로 결합
```

---

**3. 분산되는 과정**

```ts
type Result =
  StringNumberSwitch<number | string>;
```

실제로는 다음처럼 계산된다고 이해할 수 있다.

```ts
StringNumberSwitch<number>
|
StringNumberSwitch<string>
```

첫 번째:

```ts
number extends number
  ? string
  : number
```

결과:

```ts
string
```

두 번째:

```ts
string extends number
  ? string
  : number
```

결과:

```ts
number
```

최종 결과:

```ts
string | number
```

---

**4. 분산 조건부 타입의 동작 순서**

```text
1. T에 Union 타입이 들어옴

2. Union의 각 멤버를 분리

3. 각 멤버에 조건부 타입 적용

4. 계산 결과를 다시 Union으로 결합
```

즉:

```text
조건부 타입<T1 | T2>

↓

조건부 타입<T1>
|
조건부 타입<T2>
```

---

**5. Exclude 구현하기**

분산 조건부 타입을 이용하면 Union에서 특정 타입을 제거할 수 있다.

```ts
type MyExclude<T, U> =
  T extends U
    ? never
    : T;
```

의미:

```text
T가 U에 할당 가능
→ 제거하기 위해 never

그렇지 않음
→ 원래 T 유지
```

---

**6. Exclude 동작 과정**

다음 타입에서 `string`을 제거해보자.

```ts
type Result = MyExclude<
  number | string | boolean,
  string
>;
```

먼저 `T`가 분산된다.

```ts
MyExclude<number, string>
|
MyExclude<string, string>
|
MyExclude<boolean, string>
```

각각 계산한다.

```text
number extends string
→ false
→ number
```

```text
string extends string
→ true
→ never
```

```text
boolean extends string
→ false
→ boolean
```

따라서:

```ts
number | never | boolean
```

최종적으로:

```ts
number | boolean
```

---

**7. never가 사라지는 이유**

`never`는 가능한 값이 하나도 없는 타입이다.

Union에 포함되어도 추가되는 값이 없다.

```ts
number | never
```

결과:

```ts
number
```

따라서:

```ts
number | never | boolean
```

은 결국:

```ts
number | boolean
```

이 된다.

---

**8. Exclude의 핵심 원리**

```ts
type MyExclude<T, U> =
  T extends U
    ? never
    : T;
```

여기서 중요한 부분은 `T`에 Union 타입이 들어왔을 때 자동으로 분산된다는 점이다.

```text
T의 각 멤버 검사
↓
제외 대상이면 never
↓
아니면 원래 타입 유지
↓
최종 Union 생성
```

---

**9. 실제 TypeScript에도 Exclude가 있다**

TypeScript에는 같은 역할을 하는 내장 유틸리티 타입 `Exclude`가 이미 존재한다.

```ts
type Result = Exclude<
  number | string | boolean,
  string
>;
```

결과:

```ts
number | boolean
```

이번 예제의 목적은 `Exclude`를 직접 만들면서 **분산 조건부 타입이 어떻게 동작하는지 이해하는 것**이다.

---

**10. 분산이 일어나는 조건**

중요한 점은 조건식의 왼쪽에 **타입 변수 `T`가 직접 사용될 때** 분산된다는 것이다.

```ts
type Check<T> =
  T extends number
    ? string
    : boolean;
```

`T`에 Union이 들어오면 분산된다.

```ts
type Result =
  Check<number | string>;
```

```ts
string | boolean
```

즉, 모든 조건부 타입이 무조건 Union을 분산시키는 것은 아니다.

---

**11. 전체 코드**

```ts
type StringNumberSwitch<T> =
  T extends number
    ? string
    : number;

type A =
  StringNumberSwitch<number>;
// string

type B =
  StringNumberSwitch<string>;
// number

type C =
  StringNumberSwitch<number | string>;
// string | number

type MyExclude<T, U> =
  T extends U
    ? never
    : T;

type Result = MyExclude<
  number | string | boolean,
  string
>;
// number | boolean

type BuiltInResult = Exclude<
  number | string | boolean,
  string
>;
// number | boolean
```

---

**12. 핵심 정리**

* 제네릭 조건부 타입에 Union 타입을 전달하면 각 Union 멤버에 조건부 타입이 따로 적용될 수 있다.
* 이를 **분산적인 조건부 타입(Distributive Conditional Type)**이라고 한다.
* 계산된 각 결과는 다시 Union 타입으로 합쳐진다.
* `StringNumberSwitch<number | string>`은 `string | number`가 된다.
* `Exclude<T, U>`는 `T`의 각 멤버를 `U`와 비교한다.
* `U`에 해당하는 타입은 `never`로 만들고 나머지는 그대로 유지한다.
* Union 안의 `never`는 결과에서 사라진다.
* TypeScript에는 실제로 내장 `Exclude<T, U>` 유틸리티 타입이 존재한다.
* 핵심은 **`Union → 각 타입에 조건 적용 → 결과를 다시 Union으로 결합`**이다.
