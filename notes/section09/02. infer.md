# Section 9 - 2. infer

**1. infer란?**

`infer`는 **조건부 타입 안에서 특정 위치의 타입을 추론해 꺼내오는 문법**이다.

```text id="q4n6b2"
복잡한 타입
↓
infer로 특정 위치의 타입 추론
↓
추론한 타입 재사용
```

주로 함수의 반환 타입, `Promise` 내부 타입처럼 **중첩된 타입에서 필요한 부분만 추출할 때** 사용한다.

---

**2. 함수의 반환 타입 추출하기**

다음 함수 타입이 있다고 하자.

```ts id="k8z6sj"
type FuncA = () => string;
type FuncB = () => number;
```

반환 타입만 추출하고 싶다면 조건부 타입과 `infer`를 사용할 수 있다.

```ts id="y7hlco"
type MyReturnType<T> =
  T extends () => infer R
    ? R
    : never;
```

여기서:

```text id="dnr8tf"
T
→ 검사할 타입

infer R
→ 함수 반환값 위치의 타입을 R로 추론

R
→ 추론에 성공했을 때 결과 타입
```

---

**3. infer R의 의미**

```ts id="6a0dfe"
T extends () => infer R
```

의미는 다음과 같다.

```text id="d3wn14"
T가 함수 타입이라면

그 함수의 반환 타입을
R이라는 타입으로 추론하라
```

`R`은 일반적인 제네릭 타입 변수처럼 직접 전달하는 것이 아니라 TypeScript가 조건부 타입 안에서 추론한다.

---

**4. string 반환 타입 추출**

```ts id="yyfk0t"
type FuncA = () => string;

type A = MyReturnType<FuncA>;
```

계산 과정:

```text id="9807tf"
T
→ () => string

조건
→ () => string extends () => infer R

R
→ string
```

따라서:

```ts id="cr0oi1"
type A = string;
```

---

**5. number 반환 타입 추출**

```ts id="a8zw20"
type FuncB = () => number;

type B = MyReturnType<FuncB>;
```

계산:

```text id="xyldns"
() => number
extends
() => infer R

↓
R = number
```

결과:

```ts id="c8p2ol"
type B = number;
```

---

**6. 함수가 아니면 never**

```ts id="b04yts"
type C = MyReturnType<number>;
```

조건은 다음과 같다.

```ts id="o80syb"
number extends () => infer R
  ? R
  : never;
```

`number`는 함수 타입이 아니므로 `R`을 추론할 수 없다.

따라서 결과는:

```ts id="kps5nm"
type C = never;
```

---

**7. infer의 동작 흐름**

```text id="8g23q3"
1. 조건부 타입 검사

2. infer가 있는 위치에서 타입 추론 시도

3. 조건을 만족하면 해당 타입을 R에 저장

4. 참 분기에서 R 사용

5. 추론할 수 없으면 거짓 분기 사용
```

---

**8. Promise 내부 타입 추출하기**

`infer`는 `Promise` 내부 타입도 추출할 수 있다.

```ts id="cp8mco"
type PromiseUnpack<T> =
  T extends Promise<infer R>
    ? R
    : never;
```

여기서:

```text id="6r21fm"
Promise<infer R>

→ Promise 내부 타입을 R로 추론
```

---

**9. Promise<number> 추출**

```ts id="3i1d5e"
type PromiseA =
  PromiseUnpack<Promise<number>>;
```

계산:

```text id="1br70v"
Promise<number>
extends
Promise<infer R>

↓
R = number
```

결과:

```ts id="b43a0p"
type PromiseA = number;
```

---

**10. Promise<string> 추출**

```ts id="wwdgnz"
type PromiseB =
  PromiseUnpack<Promise<string>>;
```

결과:

```ts id="s99apm"
type PromiseB = string;
```

---

**11. Promise가 아니면 never**

```ts id="lw4pxu"
type PromiseC =
  PromiseUnpack<number>;
```

`number`는 `Promise<...>` 형태가 아니므로 내부 타입을 추론할 수 없다.

```ts id="r3uy21"
type PromiseC = never;
```

---

**12. infer 위치에 따라 추출 대상이 달라진다**

함수 반환값 추출:

```ts id="qn648e"
T extends () => infer R
```

```text id="ls14g8"
() => R
     ↑
반환 타입 추출
```

Promise 내부 타입 추출:

```ts id="ve5a1e"
T extends Promise<infer R>
```

```text id="jfx1g0"
Promise<R>
        ↑
내부 타입 추출
```

즉, **`infer`를 어디에 배치하느냐에 따라 어떤 타입을 추론할지가 결정된다.**

---

**13. 실제 TypeScript의 ReturnType**

TypeScript에는 함수 반환 타입을 추출하는 내장 유틸리티 타입 `ReturnType`이 이미 존재한다.

```ts id="uz8wjo"
type Func = () => string;

type Result = ReturnType<Func>;
```

결과:

```ts id="51dat2"
string
```

이번에 직접 만든 `MyReturnType`은 `infer`의 동작 원리를 이해하기 위한 예제라고 보면 된다.

---

**14. 전체 코드**

```ts id="luu4ip"
type FuncA = () => string;
type FuncB = () => number;

type MyReturnType<T> =
  T extends () => infer R
    ? R
    : never;

type A = MyReturnType<FuncA>;
// string

type B = MyReturnType<FuncB>;
// number

type C = MyReturnType<number>;
// never

type PromiseUnpack<T> =
  T extends Promise<infer R>
    ? R
    : never;

type PromiseA =
  PromiseUnpack<Promise<number>>;
// number

type PromiseB =
  PromiseUnpack<Promise<string>>;
// string

type PromiseC =
  PromiseUnpack<number>;
// never
```

---

**15. 핵심 정리**

* `infer`는 조건부 타입 안에서 특정 위치의 타입을 추론한다.
* `infer R`의 `R`은 TypeScript가 자동으로 추론하는 타입 변수다.
* `T extends () => infer R`은 함수 반환 타입을 추출한다.
* 함수 타입이 아니라면 추론에 실패하고 `never`가 될 수 있다.
* `T extends Promise<infer R>`은 `Promise` 내부 타입을 추출한다.
* `Promise<number>`에서는 `R`이 `number`가 된다.
* `Promise<string>`에서는 `R`이 `string`이 된다.
* `infer`의 위치에 따라 함수 반환 타입, Promise 내부 타입 등 서로 다른 부분을 추출할 수 있다.
* 핵심은 **`infer = 조건부 타입 안에서 타입의 일부를 변수처럼 뽑아내는 기능`**이다.
