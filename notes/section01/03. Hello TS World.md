# Section 1 - 3. Hello TS World

**1. 이번 단계의 목표**

TypeScript 코드를 직접 작성하고 실행할 수 있는 기본 실습 환경을 만든다.

```text
Node.js 패키지 생성
→ TypeScript 환경 준비
→ .ts 파일 작성
→ 컴파일
→ JavaScript 실행
```

---

**2. 프로젝트 구조**

```text
onebite-typescript
└─ section1
   ├─ src
   │  └─ index.ts
   └─ package.json
```

`section1` 폴더에서 실습을 진행한다.

---

**3. Node.js 패키지 초기화**

```bash
npm init
```

실행하면 `package.json`이 생성된다.

```text
section1
├─ src
└─ package.json
```

---

**4. Node.js 타입 정보 설치**

```bash
npm install @types/node
```

`@types/node`는 TypeScript가 Node.js에서 제공하는 기능들의 타입을 이해할 수 있도록 해준다.

```text
@types/node
→ Node.js API의 타입 정보
```

---

**5. TypeScript 컴파일러 설치**

TypeScript 컴파일러는 `tsc`이다.

```bash
npm install -g typescript
```

설치 확인:

```bash
tsc -v
```

`tsc`는 `.ts` 파일을 JavaScript 파일로 변환한다.

---

**6. TypeScript 코드 작성**

`src/index.ts`:

```ts
const message: string = "hello world";

console.log(message);
```

TypeScript 파일의 확장자는 `.ts`이다.

---

**7. tsc로 컴파일하기**

```bash
tsc src/index.ts
```

실행하면 JavaScript 파일이 생성된다.

```text
src/index.ts
↓ tsc
src/index.js
```

TypeScript 코드를 실제 실행 가능한 JavaScript 코드로 변환하는 과정이다.

---

**8. JavaScript 실행하기**

컴파일된 파일은 Node.js로 실행한다.

```bash
node src/index.js
```

전체 흐름:

```text
index.ts
→ tsc로 컴파일
→ index.js
→ node로 실행
```

즉, 기본적인 TypeScript 실행 과정은 다음 두 단계이다.

```bash
tsc src/index.ts
node src/index.js
```

---

**9. TSX로 간단하게 실행하기**

강의에서는 TypeScript 파일을 간단하게 실행하기 위해 `tsx`도 사용한다.

설치:

```bash
npm install -g tsx
```

확인:

```bash
tsx -v
```

실행:

```bash
tsx src/index.ts
```

```text
index.ts
→ tsx
→ 실행
```

별도의 `index.js` 파일을 직접 생성하고 실행하는 과정 없이 한 번에 실행할 수 있다.

---

**10. tsc와 tsx 차이**

```text
tsc + node
→ TypeScript를 JavaScript로 컴파일
→ 생성된 JavaScript 실행

tsx
→ TypeScript 파일을 간단하게 실행
```

TypeScript 자체의 컴파일 과정을 확인할 때는 `tsc`가 중요하고, 실습 과정에서 빠르게 코드를 실행할 때는 `tsx`를 사용할 수 있다.

---

**11. 전체 실습 흐름**

```text
section1 생성
→ npm init
→ @types/node 설치
→ TypeScript 설치
→ src/index.ts 작성
→ tsc로 컴파일
→ node로 실행

또는

→ tsx로 실행
```

---

**12. 핵심 정리**

* TypeScript 실습도 Node.js 패키지를 기반으로 진행할 수 있다.
* `@types/node`는 Node.js 기능의 타입 정보를 제공한다.
* TypeScript 컴파일러 명령어는 `tsc`이다.
* TypeScript 파일은 `.ts` 확장자를 사용한다.
* `tsc`는 TypeScript를 JavaScript로 변환한다.
* 생성된 JavaScript는 Node.js로 실행할 수 있다.
* `tsx`를 사용하면 TypeScript 파일을 간단하게 실행할 수 있다.
* 핵심 흐름은 **`TypeScript 작성 → 컴파일 → JavaScript 실행`**이다.
