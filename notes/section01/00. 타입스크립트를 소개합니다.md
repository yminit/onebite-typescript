# Section 1 - 0. 타입스크립트를 소개합니다

**1. 타입스크립트란?**

타입스크립트는 **자바스크립트에 타입 기능을 추가한 확장 언어**이다.

```text
JavaScript
+
Type System
↓
TypeScript
```

기존 자바스크립트 문법을 그대로 사용할 수 있고, 여기에 타입 관련 기능을 추가해서 더 안전하게 코드를 작성할 수 있다.

---

**2. 타입스크립트가 등장한 이유**

자바스크립트는 처음에는 브라우저에서 간단한 동작을 처리하기 위해 만들어졌다.

```text
버튼 클릭
→ 경고창 표시
→ 간단한 상호작용 처리
```

그래서 빠르고 유연하게 코드를 작성할 수 있도록 설계되었다.

하지만 자바스크립트의 사용 범위가 커지면서 문제가 생겼다.

```text
작은 프로그램
→ 유연함이 장점

대규모 프로그램
→ 유연함이 버그와 안정성 문제로 이어질 수 있음
```

타입스크립트는 이 문제를 보완하기 위해 등장했다.

---

**3. Node.js와 JavaScript 사용 범위 확대**

Node.js가 등장하면서 자바스크립트를 브라우저 밖에서도 실행할 수 있게 되었다.

```text
JavaScript
↓
브라우저뿐 아니라 다양한 환경에서 실행
```

그 결과 자바스크립트는 다음과 같은 분야까지 사용 범위가 넓어졌다.

```text
웹 프론트엔드
웹 서버
모바일 애플리케이션
데스크톱 애플리케이션
```

프로그램 규모가 커지면서 코드의 안정성을 높일 방법이 더 중요해졌다.

---

**4. JavaScript와 TypeScript 차이**

JavaScript:

```javascript
let age = 20;

age = "스무 살";
```

변수에 다른 타입의 값을 넣는 것이 가능하다.

TypeScript:

```typescript
let age: number = 20;

age = "스무 살";
```

`age`를 `number`로 지정했기 때문에 문자열을 할당하면 타입 오류를 확인할 수 있다.

즉, 타입스크립트는 **코드가 실행되기 전에 잘못된 타입 사용을 발견할 수 있도록 도와준다.**

---

**5. JavaScript를 다시 배울 필요는 없다**

타입스크립트는 자바스크립트와 완전히 별개의 언어가 아니다.

```text
JavaScript 문법
→ 그대로 사용

TypeScript
→ 타입 관련 기능 추가 학습
```

따라서 자바스크립트 경험이 있다면 타입스크립트에서는 주로 **타입 시스템과 타입 문법**에 집중하면 된다.

---

**6. 타입스크립트의 특징**

타입스크립트는 Microsoft에서 시작된 오픈소스 언어이다.

핵심 특징은 다음과 같다.

```text
JavaScript 기반
+
정적 타입 검사
+
대규모 코드의 안정성 향상
```

특히 규모가 커지고 여러 개발자가 함께 작업하는 프로젝트에서 타입 정보를 통해 코드의 의도와 데이터 구조를 명확하게 만들 수 있다.

---

**7. 핵심 정리**

* 타입스크립트는 **자바스크립트의 확장판**이다.
* 기존 JavaScript 문법을 그대로 사용할 수 있다.
* 추가로 타입을 정의하고 검사할 수 있다.
* JavaScript가 대규모 애플리케이션에 사용되면서 안정성 문제가 중요해졌다.
* TypeScript는 이런 문제를 줄이기 위해 타입이라는 안전장치를 추가했다.
* 핵심은 **JavaScript를 더 안전하고 예측 가능하게 작성하는 것**이다.

```text
JavaScript의 장점
+
Type System
↓
더 안전한 JavaScript 개발
```
