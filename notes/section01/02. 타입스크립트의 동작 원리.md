# Section 1 - 2. 타입스크립트의 동작 원리

**1. 컴파일이란?**

사람이 작성한 코드는 실행 환경이 바로 처리할 수 있는 형태가 아닐 수 있다.

코드를 다른 형태로 변환하는 과정을 **컴파일(Compile)**이라고 하고, 이를 수행하는 프로그램을 **컴파일러(Compiler)**라고 한다.

```text
소스 코드
→ 컴파일러
→ 실행 가능한 형태로 변환
```

---

**2. AST란?**

컴파일러는 코드를 분석하면서 **AST(Abstract Syntax Tree, 추상 문법 트리)**라는 구조를 만든다.

```text
소스 코드
→ 구문 분석
→ AST
```

AST는 코드의 문법적 구조를 트리 형태로 표현한 것이다.

---

**3. TypeScript의 핵심 동작**

TypeScript의 중요한 역할은 **JavaScript로 변환하기 전에 타입을 검사하는 것**이다.

```text
TypeScript 코드
→ 코드 분석
→ 타입 검사
→ JavaScript 코드 생성
```

예:

```typescript
const age: number = 20;
```

컴파일된 JavaScript에서는 타입 문법이 사라진다.

```javascript
const age = 20;
```

---

**4. 타입 검사는 실행 전에 이루어진다**

TypeScript는 코드 실행 전에 타입 오류를 확인한다.

```typescript
const age: number = "20";
```

`number` 변수에 문자열을 넣었기 때문에 타입 오류를 발견할 수 있다.

```text
TypeScript 작성
→ 타입 검사
→ 오류 발견
→ 개발자가 수정
```

즉, 런타임 전에 잘못된 타입 사용을 발견하는 것이 TypeScript의 핵심 역할이다.

---

**5. 타입 정보는 실행할 때 사라진다**

`number`, `string` 같은 TypeScript 타입 정보는 **타입 검사 단계에서만 사용**된다.

```typescript
const name: string = "Yumin";
```

JavaScript로 변환되면:

```javascript
const name = "Yumin";
```

```text
TypeScript 타입
→ 개발 및 타입 검사에 사용
→ JavaScript 변환 시 제거
```

따라서 브라우저나 Node.js가 TypeScript의 타입을 직접 사용하는 것은 아니다.

---

**6. JavaScript로 변환 후 실행**

TypeScript가 JavaScript로 변환되면 실제 실행은 JavaScript 실행 환경이 담당한다.

```text
TypeScript
→ 타입 검사
→ JavaScript
→ 브라우저 / Node.js
→ 실행
```

즉,

```text
TypeScript
→ 개발 단계의 안전성 제공

JavaScript
→ 실제 실행
```

으로 구분해서 이해하면 된다.

---

**7. 정확히 알아둘 점**

TypeScript를 다음처럼 이해하면 가장 정확하다.

```text
TypeScript
= JavaScript 실행 엔진이 아님

TypeScript Compiler
= 타입 검사 + JavaScript 변환

브라우저 / Node.js
= 변환된 JavaScript 실행
```

또한 **타입 오류가 있다고 항상 JavaScript 파일 생성이 중단되는 것은 아니다.**

컴파일러 설정에 따라 타입 오류가 있어도 JavaScript를 생성할 수 있으며, 오류가 있을 때 출력을 막으려면 관련 컴파일러 설정을 사용할 수 있다.

따라서 핵심은 **TypeScript가 실행 전에 타입 오류를 발견해주는 것**이다.

---

**8. 전체 흐름**

```text
TypeScript 코드 작성
        ↓
코드 분석 / AST 생성
        ↓
타입 검사
        ↓
JavaScript로 변환
        ↓
타입 문법 제거
        ↓
브라우저 / Node.js에서 실행
```

---

**9. 핵심 정리**

* 컴파일은 코드를 다른 형태로 변환하는 과정이다.
* 컴파일러는 코드를 분석하면서 AST를 만든다.
* TypeScript는 실행 전에 타입 검사를 수행한다.
* TypeScript 코드는 최종적으로 JavaScript로 변환된다.
* 타입 관련 문법은 JavaScript로 변환될 때 제거된다.
* 실제 코드는 브라우저나 Node.js의 JavaScript 실행 환경에서 실행된다.
* TypeScript의 핵심 역할은 **JavaScript가 실행되기 전에 타입 오류를 발견하는 것**이다.
* 핵심 흐름은 **`TypeScript → 타입 검사 → JavaScript → 실행`**이다.
