# Section 10 - 0. 유틸리티 타입 소개

**1. 유틸리티 타입이란?**

유틸리티 타입(Utility Type)은 **TypeScript가 미리 제공하는 타입 변환 도구**이다.

기존 타입을 자주 사용하는 형태로 쉽게 바꿀 수 있다.

```text
기존 타입
↓
유틸리티 타입 적용
↓
새로운 타입
```

---

**2. 유틸리티 타입은 타입 조작 기능으로 만들어진다**

유틸리티 타입은 지금까지 배운 타입 조작 기능을 기반으로 만들어져 있다.

대표적으로 다음 기능이 사용된다.

```text
제네릭
+
맵드 타입
+
조건부 타입
↓
유틸리티 타입
```

즉, 유틸리티 타입은 새로운 개념이라기보다 **앞에서 배운 타입 조작을 실무에서 자주 쓰는 형태로 미리 구현해 둔 것**이다.

---

**3. Partial<T>**

`Partial<T>`는 객체 타입의 모든 프로퍼티를 선택적으로 만든다.

```ts
interface User {
  id: number;
  name: string;
}

type PartialUser = Partial<User>;
```

결과:

```ts
type PartialUser = {
  id?: number;
  name?: string;
};
```

따라서 일부 프로퍼티만 사용할 수 있다.

```ts
const user: PartialUser = {
  name: "이정환",
};
```

주로 객체 일부만 수정하는 상황에서 유용하다.

---

**4. Readonly<T>**

`Readonly<T>`는 객체 타입의 모든 프로퍼티를 읽기 전용으로 만든다.

```ts
interface User {
  id: number;
  name: string;
}

type ReadonlyUser = Readonly<User>;
```

결과:

```ts
type ReadonlyUser = {
  readonly id: number;
  readonly name: string;
};
```

사용:

```ts
const user: ReadonlyUser = {
  id: 1,
  name: "이정환",
};
```

다음처럼 다시 할당할 수 없다.

```ts
user.name = "홍길동";
```

---

**5. 이미 배운 맵드 타입과 연결하기**

앞에서 직접 만들었던 타입과 거의 같은 역할이다.

직접 구현:

```ts
type MyPartial<T> = {
  [key in keyof T]?: T[key];
};
```

TypeScript 제공:

```ts
Partial<T>
```

직접 구현:

```ts
type MyReadonly<T> = {
  readonly [key in keyof T]: T[key];
};
```

TypeScript 제공:

```ts
Readonly<T>
```

즉, 유틸리티 타입을 이해하려면 앞에서 배운 `keyof`, 인덱스드 액세스 타입, 맵드 타입이 중요하다.

---

**6. 왜 유틸리티 타입을 사용할까?**

매번 새로운 타입을 직접 만들면 중복이 생긴다.

예:

```ts
interface User {
  id: number;
  name: string;
  age: number;
}
```

수정용 타입을 직접 만들면:

```ts
interface UpdateUser {
  id?: number;
  name?: string;
  age?: number;
}
```

대신:

```ts
type UpdateUser = Partial<User>;
```

로 간단하게 만들 수 있다.

```text
타입 직접 복사
→ 중복 증가

유틸리티 타입 사용
→ 기존 타입 재사용
→ 코드 간결
→ 변경 사항 자동 반영
```

---

**7. 이번 섹션의 학습 방향**

유틸리티 타입은 단순히 사용법만 외우는 것보다 내부 원리를 이해하는 것이 중요하다.

```text
유틸리티 타입 사용
+
직접 구현
↓
타입 조작 원리 이해
```

앞으로는 주로 다음 두 종류를 살펴본다.

```text
맵드 타입 기반
→ 객체 프로퍼티 변환

조건부 타입 기반
→ 조건에 따라 타입 선택·제거·추출
```

---

**8. 핵심 정리**

* 유틸리티 타입은 TypeScript가 미리 제공하는 타입 변환 도구다.
* 기존 타입을 실무에서 자주 사용하는 형태로 쉽게 변환할 수 있다.
* 제네릭, 맵드 타입, 조건부 타입 등의 타입 조작 기능을 기반으로 만들어져 있다.
* `Partial<T>`는 모든 프로퍼티를 선택적으로 만든다.
* `Readonly<T>`는 모든 프로퍼티를 읽기 전용으로 만든다.
* 직접 새로운 타입을 반복해서 작성하는 중복을 줄일 수 있다.
* 기존 타입이 변경되면 이를 기반으로 한 유틸리티 타입에도 변경 사항이 반영된다.
* 앞으로는 유틸리티 타입을 직접 구현하면서 내부 동작 원리까지 학습한다.
* 핵심은 **`유틸리티 타입 = 자주 사용하는 타입 변환을 TypeScript가 미리 만들어 둔 도구`**이다.
