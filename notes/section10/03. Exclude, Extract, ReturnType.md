# Section 10 - 3. Exclude, Extract, ReturnType

**1. 이번 시간의 핵심**

이번에는 조건부 타입을 기반으로 한 세 가지 유틸리티 타입을 다룬다.

```text
Exclude<T, U>
→ T에서 U 제거

Extract<T, U>
→ T에서 U에 해당하는 타입만 추출

ReturnType<T>
→ 함수의 반환 타입 추출
```

---

**2. Exclude<T, U>**

`Exclude<T, U>`는 `T`에서 `U`에 해당하는 타입을 제거한다.

```ts
type A = Exclude<
  string | boolean,
  string
>;
```

결과:

```ts
type A = boolean;
```

즉:

```text
string | boolean
↓ string 제거
boolean
```

---

**3. Exclude 직접 구현하기**

```ts
type MyExclude<T, U> =
  T extends U
    ? never
    : T;
```

의미:

```text
T가 U에 할당 가능
→ never로 제거

그렇지 않음
→ T 유지
```

---

**4. Exclude의 분산 과정**

```ts
type A = MyExclude<
  string | boolean,
  string
>;
```

`T`가 Union이므로 각 멤버에 조건부 타입이 적용된다.

```text
string
→ string extends string
→ never

boolean
→ boolean extends string
→ boolean
```

결과:

```ts
never | boolean
```

`never`는 Union에서 사라지므로:

```ts
boolean
```

이 된다.

---

**5. Extract<T, U>**

`Extract<T, U>`는 `T`에서 `U`에 해당하는 타입만 남긴다.

```ts
type B = Extract<
  string | boolean,
  string
>;
```

결과:

```ts
type B = string;
```

즉:

```text
string | boolean
↓ string에 해당하는 타입만 추출
string
```

---

**6. Extract 직접 구현하기**

```ts
type MyExtract<T, U> =
  T extends U
    ? T
    : never;
```

의미:

```text
T가 U에 할당 가능
→ T 유지

그렇지 않음
→ never로 제거
```

---

**7. Extract의 분산 과정**

```ts
type B = MyExtract<
  string | boolean,
  string
>;
```

각 Union 멤버를 검사한다.

```text
string
→ string extends string
→ string

boolean
→ boolean extends string
→ never
```

결과:

```ts
string | never
```

최종적으로:

```ts
string
```

이 된다.

---

**8. Exclude와 Extract 비교**

```ts
type MyExclude<T, U> =
  T extends U
    ? never
    : T;
```

```ts
type MyExtract<T, U> =
  T extends U
    ? T
    : never;
```

차이는 참과 거짓일 때 반환하는 타입이다.

```text
Exclude
→ 조건에 맞으면 제거

Extract
→ 조건에 맞으면 유지
```

---

**9. ReturnType<T>**

`ReturnType<T>`은 **함수 타입의 반환값 타입을 추출**한다.

```ts
function funcA() {
  return "hello";
}

function funcB() {
  return 10;
}
```

사용:

```ts
type ReturnA =
  ReturnType<typeof funcA>;

type ReturnB =
  ReturnType<typeof funcB>;
```

결과:

```ts
type ReturnA = string;
type ReturnB = number;
```

---

**10. typeof와 함께 사용하는 이유**

`funcA`와 `funcB`는 값이다.

따라서 먼저 `typeof`로 함수 타입을 얻는다.

```ts
typeof funcA
```

결과:

```ts
() => string
```

이 타입을 `ReturnType`에 전달한다.

```text
funcA
↓
typeof funcA
↓
() => string
↓
ReturnType
↓
string
```

---

**11. ReturnType 직접 구현하기**

```ts
type MyReturnType<
  T extends (...args: any[]) => any
> =
  T extends (...args: any[]) => infer R
    ? R
    : never;
```

핵심:

```text
(...args: any[]) => infer R
                    ↑
                반환 타입 추론
```

`infer R`이 함수 반환 위치의 타입을 추론한다.

---

**12. 반환 타입 추론 과정**

```ts
type Func = () => string;

type Result =
  MyReturnType<Func>;
```

계산:

```text
() => string

extends

(...args: any[]) => infer R

↓
R = string
```

결과:

```ts
type Result = string;
```

---

**13. 매개변수가 있는 함수도 가능하다**

```ts
type Func = (
  a: number,
  b: number
) => boolean;
```

```ts
type Result =
  ReturnType<Func>;
```

결과:

```ts
boolean
```

반환 타입만 추출하므로 함수의 매개변수 개수나 타입은 핵심 대상이 아니다.

---

**14. 세 유틸리티 타입의 연결**

```text
Exclude<T, U>
→ 분산 조건부 타입
→ 조건에 맞는 타입 제거

Extract<T, U>
→ 분산 조건부 타입
→ 조건에 맞는 타입 유지

ReturnType<T>
→ 조건부 타입 + infer
→ 함수 반환 타입 추출
```

앞에서 배운 **분산 조건부 타입과 `infer`가 실제 유틸리티 타입 구현에 사용되는 사례**라고 보면 된다.

---

**15. 전체 코드**

```ts
type MyExclude<T, U> =
  T extends U
    ? never
    : T;

type A = MyExclude<
  string | boolean,
  string
>;

type MyExtract<T, U> =
  T extends U
    ? T
    : never;

type B = MyExtract<
  string | boolean,
  string
>;

type MyReturnType<
  T extends (...args: any[]) => any
> =
  T extends (...args: any[]) => infer R
    ? R
    : never;

function funcA() {
  return "hello";
}

function funcB() {
  return 10;
}

type ReturnA =
  MyReturnType<typeof funcA>;

type ReturnB =
  MyReturnType<typeof funcB>;
```

---

**16. 핵심 정리**

* `Exclude<T, U>`는 `T`에서 `U`에 해당하는 타입을 제거한다.
* `Exclude`는 `T extends U ? never : T` 형태의 분산 조건부 타입으로 이해할 수 있다.
* `Extract<T, U>`는 `T`에서 `U`에 해당하는 타입만 남긴다.
* `Extract`는 `T extends U ? T : never` 형태로 동작한다.
* `Exclude`와 `Extract`는 서로 반대되는 역할을 한다.
* `ReturnType<T>`은 함수 타입의 반환값 타입을 추출한다.
* 함수 값에서 타입이 필요하면 `typeof 함수`를 사용한다.
* `ReturnType`은 조건부 타입과 `infer`를 이용해 반환 타입을 추론한다.
* 핵심은 **`Exclude = 제거`, `Extract = 추출`, `ReturnType = 함수 반환 타입 추출`**이다.
