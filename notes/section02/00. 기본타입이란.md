# Section 2 - 0. 기본 타입이란

**1. 기본 타입이란?**

기본 타입은 TypeScript가 기본적으로 제공하는 **내장 타입**이다.

대표적으로 다음과 같은 타입이 있다.

```text
number
string
null
undefined
any
unknown
void
never
```

각 타입 사이에는 포함 관계와 계층 구조가 있으며, 이 내용은 이후에 자세히 학습한다.

---

**2. 이번 섹션의 학습 범위**

기본 타입을 다음 순서로 학습한다.

```text
1. 원시 타입
   → number, string 등

2. 비원시 타입
   → 객체, 배열 등

3. 특별한 타입
   → any
   → unknown
   → void
   → never
```

현재 단계에서는 **TypeScript에 여러 종류의 기본 타입이 존재한다는 것**만 이해하면 된다.

---

**3. section2 실습 환경**

새로운 실습 폴더를 만든다.

```text
onebite-typescript
├─ section1
└─ section2
```

패키지를 초기화한다.

```bash
npm init
```

Node.js 타입 정보를 설치한다.

```bash
npm install @types/node
```

---

**4. tsconfig.json**

이전 섹션과 동일한 설정을 사용한다.

```json
{
  "compilerOptions": {
    "target": "ESNext",
    "module": "commonjs",
    "skipLibCheck": true,
    "rootDir": "./src",
    "outDir": "./dist",
    "strict": false,
    "moduleDetection": "force"
  },
  "include": ["src"]
}
```

이번 섹션에서는 이미 배운 컴파일러 옵션 자체보다 **기본 타입 학습에 집중하면 된다.**

---

**5. 프로젝트 구조**

```text
section2
├─ src
│  └─ index.ts
├─ package.json
└─ tsconfig.json
```

`src/index.ts`에 TypeScript 코드를 작성한다.

```ts
console.log("Hello TypeScript");
```

---

**6. 컴파일과 실행**

컴파일:

```bash
tsc
```

실행:

```bash
node dist/index.js
```

전체 흐름:

```text
src/index.ts
→ tsc
→ dist/index.js
→ node로 실행
```

---

**7. 핵심 정리**

* 기본 타입은 TypeScript가 제공하는 내장 타입이다.
* 이번 섹션에서는 **원시 타입 → 비원시 타입 → 특별한 타입** 순서로 학습한다.
* `any`, `unknown`, `void`, `never` 같은 TypeScript 특유의 타입도 배운다.
* 실습 코드는 `section2/src`에서 작성한다.
* 프로젝트 설정은 이전 섹션과 동일하므로 반복해서 외우기보다 **타입 학습에 집중하면 된다.**
