# Section 2 - 1. 원시 타입과 리터럴 타입

**1. 원시 타입**

원시 타입은 숫자, 문자열처럼 **하나의 값을 표현하는 기본 타입**이다.

대표적인 타입은 다음과 같다.

```text id="nsm0m1"
number
string
boolean
null
undefined
```

---

**2. 타입 주석**

변수 이름 뒤에 타입을 직접 작성할 수 있다.

```ts id="qz9j7n"
let num: number = 123;
```

이 문법을 **타입 주석(Type Annotation)**이라고 한다.

```text id="xav2b0"
변수명: 타입
```

---

**3. number**

`number`는 JavaScript의 숫자 값을 표현한다.

```ts id="y54v6o"
let num1: number = 123;
let num2: number = -123;
let num3: number = 0.123;
let num4: number = Infinity;
let num5: number = NaN;
```

`number` 타입 변수에는 숫자가 아닌 값을 할당할 수 없다.

---

**4. string**

`string`은 문자열 값을 표현한다.

```ts id="vzf2g6"
let str1: string = "hello";
let str2: string = 'hello';
let str3: string = `hello`;
let str4: string = `hello ${num1}`;
```

큰따옴표, 작은따옴표, 백틱, 템플릿 리터럴 모두 `string`이다.

---

**5. boolean**

`boolean`은 두 값만 가진다.

```ts id="76i9qn"
let bool1: boolean = true;
let bool2: boolean = false;
```

```text id="g3ilpm"
boolean
├─ true
└─ false
```

---

**6. null과 undefined**

`null` 타입은 `null`만 저장할 수 있다.

```ts id="90m97n"
let nullValue: null = null;
```

`undefined` 타입은 `undefined`만 저장할 수 있다.

```ts id="t57wq0"
let undefinedValue: undefined = undefined;
```

---

**7. strictNullChecks**

`strictNullChecks`는 `null`, `undefined`를 다른 타입과 엄격하게 구분할지 결정한다.

```text id="bcik8l"
strictNullChecks: true
→ number 등에 null 할당 불가

strictNullChecks: false
→ null 할당을 더 느슨하게 허용
```

현재 학습 설정에서는

```json id="ypjrfy"
"strict": false
```

를 사용하므로 엄격한 null 검사가 비활성화된다.

실무에서는 일반적으로 엄격한 타입 검사를 사용하는 방향으로 학습하는 것이 중요하다.

---

**8. 리터럴 타입**

리터럴 타입은 **특정 값 하나만 허용하는 타입**이다.

일반 타입:

```ts id="9htvzy"
let num: number = 10;
```

`number`에 포함되는 여러 숫자를 저장할 수 있다.

리터럴 타입:

```ts id="k28whl"
let num: 10 = 10;
```

이 변수에는 `10`만 저장할 수 있다.

---

**9. 리터럴 타입 종류**

숫자:

```ts id="7sm1bf"
let numA: 10 = 10;
```

문자열:

```ts id="puibxd"
let strA: "hello" = "hello";
```

불리언:

```ts id="x9gphg"
let boolA: true = true;
```

```text id="ecdpux"
number
→ 여러 숫자

10
→ 숫자 10 하나만

string
→ 여러 문자열

"hello"
→ "hello" 하나만
```

---

**10. 핵심 정리**

* `number`, `string`, `boolean`, `null`, `undefined`는 대표적인 원시 타입이다.
* `변수명: 타입` 형태를 타입 주석이라고 한다.
* `number`는 JavaScript의 숫자 값을 표현한다.
* `string`은 문자열 값을 표현한다.
* `boolean`은 `true`, `false`를 표현한다.
* `null`, `undefined`도 각각 독립적인 타입이다.
* `strictNullChecks`는 `null`과 `undefined`를 얼마나 엄격하게 검사할지 결정한다.
* 리터럴 타입은 **특정 값 하나만 허용하는 타입**이다.
* 핵심 차이는 **`number`는 값의 집합, `10`은 하나의 값만 허용하는 타입**이라고 이해하면 된다.
