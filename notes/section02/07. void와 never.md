# Section 2 - 7. void와 never

**1. void 타입**

`void`는 **함수가 의미 있는 반환값을 반환하지 않는 경우** 사용하는 타입이다.

```ts
function printMessage(): void {
  console.log("hello");
}
```

함수는 정상적으로 끝나지만 반환값을 사용하지 않는다는 의미이다.

```text
함수 실행
→ 정상 종료
→ 반환값 없음
```

---

**2. void와 undefined의 차이**

`undefined`를 반환 타입으로 지정하면 실제 반환값 자체가 `undefined`여야 한다.

```ts
function func(): undefined {
  return undefined;
}
```

반면 `void`는 반환값이 없는 함수를 표현할 때 자연스럽게 사용할 수 있다.

```ts
function func(): void {
  console.log("hello");
}
```

따라서 일반적으로 **반환값을 사용하지 않는 함수에는 `void`를 사용한다.**

---

**3. void 타입의 변수**

`void`는 변수 타입으로도 사용할 수 있지만 주로 함수 반환 타입에서 사용한다.

```ts
let value: void = undefined;
```

현재 학습 설정처럼 엄격한 null 검사가 비활성화되어 있다면 `null`이 허용될 수도 있다.

하지만 실무에서는 `void`를 일반 변수 타입으로 사용할 일은 거의 없다.

---

**4. never 타입**

`never`는 **값이 존재할 수 없는 타입**이다.

대표적으로 함수가 정상적으로 끝나는 일이 없는 경우 사용한다.

무한 반복:

```ts
function loop(): never {
  while (true) {}
}
```

예외 발생:

```ts
function throwError(): never {
  throw new Error("error");
}
```

두 함수 모두 호출 이후 정상적으로 반환되는 값이 없다.

---

**5. void와 never의 핵심 차이**

```text
void
→ 함수가 정상적으로 끝남
→ 반환값을 사용하지 않음

never
→ 함수가 정상적으로 끝날 수 없음
→ 반환 자체가 발생하지 않음
```

예:

```ts
function func1(): void {
  console.log("hello");
}
```

```ts
function func2(): never {
  throw new Error();
}
```

`func1`은 실행을 끝내고 호출한 위치로 돌아온다.

`func2`는 예외를 발생시키기 때문에 정상적으로 돌아오지 않는다.

---

**6. never 타입에는 값을 넣을 수 없다**

```ts
let value: never;
```

`never`는 가능한 값이 하나도 없는 타입이므로 일반적인 값을 할당할 수 없다.

```ts
// 모두 오류
value = 1;
value = "hello";
value = true;
value = undefined;
value = null;
```

`any` 값도 `never`에는 할당할 수 없다.

---

**7. void와 never 비교**

```text
void
→ "반환해서 사용할 값이 없다"
→ 함수는 정상 종료

never
→ "가능한 값 자체가 없다"
→ 함수가 정상 종료하지 않음
```

`never`는 이후 타입 좁히기나 유니온 타입을 배울 때도 중요하게 사용된다.

---

**8. 핵심 코드**

```ts
function printMessage(): void {
  console.log("hello");
}

function infiniteLoop(): never {
  while (true) {}
}

function throwError(): never {
  throw new Error("error");
}

let voidValue: void = undefined;

let neverValue: never;
```

---

**9. 핵심 정리**

* `void`는 주로 반환값이 없는 함수의 반환 타입으로 사용한다.
* `void` 함수는 정상적으로 실행을 마친다.
* `void` 타입 변수에는 `undefined`를 저장할 수 있다.
* 일반적으로 `void`를 변수 타입으로 직접 사용하는 경우는 드물다.
* `never`는 **가능한 값이 하나도 없는 타입**이다.
* 무한 반복 함수나 항상 예외를 발생시키는 함수의 반환 타입으로 사용할 수 있다.
* `never` 타입에는 일반적인 어떤 값도 할당할 수 없다.
* 핵심 차이는 **`void = 정상 종료하지만 반환값 없음`, `never = 정상 종료 자체가 없음`**이다.
