# Section 2 - 5. 열거형 타입

**1. enum이란?**

`enum`은 **서로 관련된 여러 값을 하나의 이름 아래 묶어서 사용하는 타입**이다.

```ts
enum Role {
  ADMIN,
  USER,
  GUEST,
}
```

다음과 같은 고정된 값들을 관리할 때 사용할 수 있다.

```text
사용자 권한
언어 코드
상태 값
카테고리
```

---

**2. 숫자형 enum**

숫자형 `enum`은 멤버에 숫자 값을 사용할 수 있다.

```ts
enum Role {
  ADMIN = 0,
  USER = 1,
  GUEST = 2,
}
```

각 멤버는 다음 값을 가진다.

```text
Role.ADMIN → 0
Role.USER  → 1
Role.GUEST → 2
```

---

**3. 숫자 자동 할당**

숫자를 직접 지정하지 않으면 `0`부터 자동으로 증가한다.

```ts
enum Role {
  ADMIN,
  USER,
  GUEST,
}
```

```text
ADMIN → 0
USER  → 1
GUEST → 2
```

시작값을 직접 지정할 수도 있다.

```ts
enum Role {
  ADMIN = 10,
  USER,
  GUEST,
}
```

```text
ADMIN → 10
USER  → 11
GUEST → 12
```

---

**4. enum 멤버 사용하기**

`enum` 멤버는 실제 값처럼 사용할 수 있다.

```ts
enum Role {
  ADMIN,
  USER,
  GUEST,
}

const user = {
  name: "이정환",
  role: Role.ADMIN,
};
```

직접 숫자를 작성하는 것보다 의미가 명확해진다.

```text
role: 0
→ 의미를 바로 알기 어려움

role: Role.ADMIN
→ 관리자 권한이라는 의미가 명확함
```

---

**5. 문자열 enum**

문자열도 `enum` 값으로 사용할 수 있다.

```ts
enum Language {
  KOREAN = "ko",
  ENGLISH = "en",
}
```

문자열 `enum`은 숫자형과 달리 값을 자동으로 증가시킬 수 없기 때문에 각 값을 직접 작성한다.

사용:

```ts
const user = {
  name: "이정환",
  language: Language.KOREAN,
};
```

---

**6. 문자열 enum의 장점**

문자열 값을 직접 작성하면 오타가 생길 수 있다.

```ts
const user = {
  language: "kor",
};
```

정해진 값만 사용하도록 `enum`으로 관리하면 이런 실수를 줄일 수 있다.

```ts
const user = {
  language: Language.KOREAN,
};
```

즉,

```text
문자열 직접 입력
→ 오타 가능

enum 멤버 사용
→ 미리 정의된 값 사용
```

---

**7. enum은 런타임에도 존재한다**

`type` 같은 일반적인 타입 문법은 JavaScript로 컴파일할 때 사라진다.

```ts
type User = {
  name: string;
};
```

반면 일반 `enum`은 JavaScript 코드로 변환되어 런타임에도 존재한다.

```ts
enum Role {
  ADMIN,
  USER,
  GUEST,
}
```

```text
type
→ 타입 검사에만 사용
→ 컴파일 후 제거

enum
→ 타입으로 사용
→ JavaScript 코드로도 생성
```

이 점이 일반적인 TypeScript 타입 문법과의 중요한 차이이다.

---

**8. 전체 예제**

```ts
enum Role {
  ADMIN,
  USER,
  GUEST,
}

enum Language {
  KOREAN = "ko",
  ENGLISH = "en",
}

const user1 = {
  name: "이정환",
  role: Role.ADMIN,
  language: Language.KOREAN,
};

const user2 = {
  name: "홍길동",
  role: Role.USER,
  language: Language.ENGLISH,
};

const user3 = {
  name: "아무개",
  role: Role.GUEST,
  language: Language.KOREAN,
};
```

---

**9. 핵심 정리**

* `enum`은 관련된 여러 값을 하나의 이름으로 묶는 문법이다.
* 숫자형 `enum`은 값을 생략하면 `0`부터 자동 증가한다.
* 시작 숫자를 지정하면 이후 값도 자동 증가한다.
* 문자열 `enum`은 각 값을 직접 지정한다.
* `Role.ADMIN`처럼 사용하면 숫자나 문자열을 직접 작성하는 것보다 의미가 명확하다.
* 권한, 언어 코드처럼 **정해진 값 집합**을 표현할 때 사용할 수 있다.
* 일반적인 타입 문법은 컴파일 후 사라지지만, 일반 `enum`은 JavaScript 코드로 생성된다.
* 핵심은 **`enum = 제한된 값들을 이름으로 관리하는 방법`**이다.
