# Section 2 - 2. 배열과 튜플

**1. 배열 타입**

배열 타입은 **배열에 어떤 타입의 값이 들어갈 수 있는지** 정의한다.

숫자 배열:

```ts
const numArr: number[] = [1, 2, 3];
```

문자열 배열:

```ts
const strArr: string[] = ["hello", "im", "winterlood"];
```

기본 형태는 다음과 같다.

```text
요소타입[]
```

---

**2. Array 타입 표현**

배열 타입은 제네릭 문법으로도 작성할 수 있다.

```ts
const boolArr: Array<boolean> = [true, false, true];
```

다음 두 표현은 같은 의미이다.

```ts
boolean[]
```

```ts
Array<boolean>
```

현재 단계에서는 더 간단한 `boolean[]` 형태를 주로 사용하면 된다.

---

**3. 여러 타입을 가진 배열**

숫자와 문자열을 함께 저장하려면 유니온 타입을 사용한다.

```ts
const multiArr: (number | string)[] = [1, "hello"];
```

```text
number | string
→ number 또는 string
```

즉, 배열의 각 요소가 `number` 또는 `string`이면 된다.

---

**4. 다차원 배열**

배열 안에 배열이 들어가는 경우 대괄호를 추가한다.

```ts
const doubleArr: number[][] = [
  [1, 2, 3],
  [4, 5],
];
```

```text
number[]
→ 숫자 배열

number[][]
→ 숫자 배열을 요소로 갖는 배열
```

---

**5. 튜플 타입**

튜플은 **각 위치의 타입과 길이를 정해놓은 배열 타입**이다.

```ts
const tup1: [number, number] = [1, 2];
```

이 튜플은 다음 구조를 가진다.

```text
0번 위치 → number
1번 위치 → number
```

각 위치마다 다른 타입도 지정할 수 있다.

```ts
const tup2: [number, string, boolean] = [
  1,
  "2",
  true,
];
```

튜플에서는 **값의 순서가 중요하다.**

---

**6. 배열과 튜플의 차이**

```text
배열
→ 요소의 타입 지정
→ 길이는 자유로움

튜플
→ 각 위치의 타입 지정
→ 길이와 순서가 중요
```

예:

```ts
const users: [string, number][] = [
  ["이정환", 1],
  ["이아무개", 2],
  ["김아무개", 3],
];
```

각 회원 데이터는 반드시 다음 순서를 따라야 한다.

```text
[이름, 회원번호]
[string, number]
```

따라서 다음과 같은 실수를 타입으로 확인할 수 있다.

```ts
// [5, "최아무개"]
```

---

**7. 튜플도 실제로는 배열**

TypeScript의 튜플은 JavaScript로 변환되면 일반 배열이 된다.

따라서 배열 메서드도 사용할 수 있다.

```ts
push()
pop()
```

이 때문에 타입 수준에서는 길이를 정했더라도 배열 메서드를 사용할 때는 주의해야 한다.

즉, 튜플은 **런타임에 새로운 자료구조가 생기는 것이 아니라 TypeScript가 배열의 구조를 더 엄격하게 검사하는 타입**이다.

---

**8. 핵심 코드**

```ts
const numArr: number[] = [1, 2, 3];

const strArr: string[] = [
  "hello",
  "im",
  "winterlood",
];

const boolArr: boolean[] = [
  true,
  false,
  true,
];

const multiArr: (number | string)[] = [
  1,
  "hello",
];

const doubleArr: number[][] = [
  [1, 2, 3],
  [4, 5],
];

const tup1: [number, number] = [1, 2];

const tup2: [number, string, boolean] = [
  1,
  "2",
  true,
];

const users: [string, number][] = [
  ["이정환", 1],
  ["이아무개", 2],
  ["김아무개", 3],
];
```

---

**9. 핵심 정리**

* 배열 타입은 `요소타입[]` 형태로 정의한다.
* `Array<타입>` 형태로도 작성할 수 있다.
* 여러 타입을 허용하려면 유니온 타입을 사용한다.
* `number[][]`처럼 작성하면 다차원 배열을 표현할 수 있다.
* 튜플은 **위치별 타입과 길이가 정해진 배열 타입**이다.
* 튜플에서는 요소의 순서가 중요하다.
* `[string, number][]`는 `[string, number]` 형태의 튜플을 여러 개 저장하는 배열이다.
* 튜플도 JavaScript로 변환되면 일반 배열이다.
* 핵심 차이는 **`배열 = 요소 타입 중심`, `튜플 = 위치와 순서까지 타입으로 표현`**이다.
