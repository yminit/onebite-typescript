# Section 3 - 2. 타입 계층도와 함께 기본 타입 살펴보기

**1. unknown**

`unknown`은 **모든 타입의 슈퍼 타입**으로 볼 수 있다.

```text
number  ─┐
string  ─┤
boolean ─┤→ unknown
object  ─┤
기타 타입 ─┘
```

즉, 어떤 값이든 `unknown` 타입 변수에 할당할 수 있다.

```ts
let value: unknown;

value = 10;
value = "hello";
value = true;
value = {};
```

하지만 반대로 `unknown` 값을 다른 타입에 바로 할당할 수는 없다.

```ts
let value: unknown = 10;

// 오류
let num: number = value;
```

```text
모든 타입
→ unknown

가능

unknown
→ 다른 구체적인 타입

바로는 불가능
```

---

**2. unknown은 전체 집합에 가깝다**

타입을 집합으로 보면 `unknown`은 모든 타입의 값을 포함하는 가장 큰 타입이다.

```text
unknown
┌───────────────────────┐
│ number                │
│ string                │
│ boolean               │
│ object                │
│ ...                   │
└───────────────────────┘
```

따라서 모든 일반 타입은 `unknown`의 서브 타입이다.

---

**3. never**

`never`는 **가능한 값이 하나도 없는 타입**이다.

집합으로 보면 공집합에 해당한다.

```text
never = ∅
```

예:

```ts
function throwError(): never {
  throw new Error("error");
}
```

이 함수는 정상적으로 값을 반환할 수 없다.

---

**4. never는 모든 타입의 서브 타입**

공집합은 모든 집합의 부분 집합이므로 `never`도 모든 타입의 서브 타입이다.

```text
never
↓
number
string
boolean
void
unknown
...
```

따라서 `never` 타입의 값은 다른 타입으로 할당할 수 있다.

반대로 다른 타입의 값을 `never`에 넣을 수는 없다.

```ts
let value: never;

// 모두 오류
value = 10;
value = "hello";
value = undefined;
```

---

**5. void**

`void`는 주로 **의미 있는 반환값이 없는 함수**에서 사용한다.

```ts
function printMessage(): void {
  console.log("hello");
}
```

`undefined`는 `void`로 취급할 수 있다.

```text
undefined
↓
void
```

따라서 다음과 같은 관계로 이해할 수 있다.

```text
void
↑
undefined
↑
never
```

---

**6. any**

`any`는 일반적인 타입 계층 규칙을 거의 무시한다.

```ts
let value: any;

value = 10;
value = "hello";

let num: number = value;
let str: string = value;
```

즉,

```text
다른 타입 → any
any → 다른 타입
```

이 모두 대부분 허용된다.

그래서 `any`는 정상적인 슈퍼 타입·서브 타입 관계로 이해하기보다 **타입 검사를 우회하는 특별한 타입**으로 보는 것이 더 정확하다.

단, `never`에는 `any`도 할당할 수 없다.

---

**7. 네 타입의 관계**

핵심만 단순화하면 다음과 같다.

```text
        unknown
           ↑
     일반적인 타입들
           ↑
          void
           ↑
       undefined
           ↑
         never
```

`any`는 이 계층 바깥에서 타입 검사를 느슨하게 만드는 특별한 타입이다.

---

**8. 타입별 핵심 역할**

```text
unknown
→ 모든 값을 받을 수 있음
→ 사용 전 타입 확인 필요

never
→ 가능한 값이 없음
→ 모든 타입의 서브 타입

void
→ 의미 있는 반환값이 없는 함수

any
→ 타입 검사 우회
→ 대부분의 타입과 자유롭게 할당 가능
```

---

**9. 핵심 정리**

* `unknown`은 모든 일반 타입의 슈퍼 타입이다.
* 모든 타입의 값은 `unknown`에 할당할 수 있다.
* `unknown` 값을 구체적인 타입으로 바로 사용할 수는 없다.
* `never`는 가능한 값이 하나도 없는 공집합 타입이다.
* `never`는 모든 타입의 서브 타입이다.
* 다른 타입의 값은 `never`에 할당할 수 없다.
* `void`는 주로 반환값이 없는 함수에서 사용한다.
* `undefined`는 `void`의 서브 타입으로 볼 수 있다.
* `any`는 일반적인 타입 계층 규칙을 대부분 무시한다.
* 핵심은 **`unknown = 가장 넓은 타입`, `never = 가장 좁은 타입`**으로 이해하는 것이다.
