# Section 3 - 1. 타입은 집합이다

**1. 타입은 값의 집합이다**

TypeScript에서 타입은 **해당 타입에 속할 수 있는 값들의 집합**으로 이해할 수 있다.

예를 들어 `number` 타입은 여러 숫자 값을 포함한다.

```text id="e4myn1"
number
→ 1
→ 10
→ -123
→ 0.5
→ ...
```

즉, 어떤 값이 특정 타입에 속한다는 것은 **그 값이 해당 타입의 집합에 포함된다**는 의미이다.

---

**2. 리터럴 타입도 집합이다**

리터럴 타입은 **특정 값 하나만 포함하는 타입**이다.

```ts id="5jv9ut"
let num: 20 = 20;
```

`20` 리터럴 타입은 숫자 `20` 하나만 포함한다.

```text id="dgj50h"
number
└─ 여러 숫자 포함

20
└─ 숫자 20 하나만 포함
```

따라서 `20` 리터럴 타입은 `number` 타입에 포함되는 더 작은 집합이다.

---

**3. 슈퍼 타입과 서브 타입**

두 타입이 포함 관계를 가진다면 큰 타입을 **슈퍼 타입**, 작은 타입을 **서브 타입**이라고 한다.

```text id="d9lb7g"
number
  ↑
  20
```

여기서는:

```text id="uqwwck"
number
→ 슈퍼 타입

20
→ 서브 타입
```

`20`에 속하는 모든 값은 `number`에도 속하기 때문이다.

---

**4. 타입 호환성**

타입 호환성은 **한 타입의 값을 다른 타입의 값으로 취급할 수 있는지**를 판단하는 것이다.

서브 타입의 값은 슈퍼 타입의 변수에 할당할 수 있다.

```ts id="d93g51"
let num: number = 10;
let literal: 10 = 10;

num = literal;
```

`10`은 항상 `number`이므로 안전하다.

```text id="0yxiev"
10 리터럴 타입
→ number 타입

가능
```

---

**5. 반대 방향은 불가능하다**

슈퍼 타입의 값을 서브 타입 변수에 바로 넣을 수는 없다.

```ts id="ejh3gb"
let num: number = 10;
let literal: 10 = 10;

literal = num;
```

`num`의 타입은 `number`이므로 실제로는 `10`이 아닌 다른 숫자가 들어 있을 수도 있다.

```ts id="azgzkj"
num = 999;
```

하지만 `literal`에는 `10`만 들어갈 수 있다.

따라서 TypeScript는 이 할당을 허용하지 않는다.

---

**6. 집합으로 보면 이해가 쉽다**

```text id="aofyq1"
number
= { 1, 2, 3, 10, 20, 999, ... }

10
= { 10 }
```

작은 집합의 값은 큰 집합에도 항상 포함된다.

```text id="mrevwr"
{ 10 }
→ number

가능
```

하지만 큰 집합의 값이 작은 집합에 항상 포함된다고 보장할 수는 없다.

```text id="ln4x6j"
number
→ { 10 }

보장할 수 없음
```

---

**7. 업 캐스팅**

서브 타입의 값을 슈퍼 타입으로 취급하는 것을 **업 캐스팅**이라고 한다.

```ts id="l63c4m"
let num: number = 10;
let literal: 10 = 10;

num = literal;
```

```text id="n9lg71"
서브 타입
↓
슈퍼 타입

10
↓
number
```

타입 집합이 작은 쪽에서 큰 쪽으로 이동하므로 안전하다.

---

**8. 다운 캐스팅**

슈퍼 타입의 값을 서브 타입으로 취급하는 것을 **다운 캐스팅**이라고 한다.

```ts id="5kokcq"
let num: number = 10;
let literal: 10 = 10;

literal = num;
```

```text id="ckliv5"
슈퍼 타입
↓
서브 타입

number
↓
10
```

더 큰 집합의 값이 작은 집합의 조건을 만족한다고 보장할 수 없기 때문에 일반적으로 허용되지 않는다.

---

**9. 핵심 구조**

```text id="a7uxny"
타입
→ 값들의 집합

서브 타입
→ 더 작은 집합

슈퍼 타입
→ 더 큰 집합

서브 타입 → 슈퍼 타입
→ 할당 가능

슈퍼 타입 → 서브 타입
→ 일반적으로 할당 불가
```

---

**10. 핵심 정리**

* TypeScript의 타입은 **값들의 집합**으로 이해할 수 있다.
* 리터럴 타입은 특정 값 하나만 포함하는 작은 집합이다.
* `10` 같은 숫자 리터럴 타입은 `number`의 서브 타입이다.
* 다른 타입을 포함하는 큰 타입을 **슈퍼 타입**이라고 한다.
* 다른 타입에 포함되는 작은 타입을 **서브 타입**이라고 한다.
* 타입 호환성은 한 타입의 값을 다른 타입으로 취급할 수 있는지 판단하는 것이다.
* 서브 타입의 값을 슈퍼 타입으로 할당하는 것은 가능하다.
* 이를 **업 캐스팅**이라고 한다.
* 슈퍼 타입을 서브 타입으로 할당하는 것은 일반적으로 허용되지 않는다.
* 이를 **다운 캐스팅**이라고 한다.
* 핵심은 **`타입의 포함 관계가 할당 가능 여부를 결정한다`**는 것이다.
