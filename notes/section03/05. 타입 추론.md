# Section 3 - 5. 타입 추론

**1. 타입 추론이란?**

TypeScript는 타입을 직접 작성하지 않아도 코드의 값을 분석해 타입을 자동으로 판단할 수 있다.

```ts
let num = 10;
```

```text
num
→ number로 추론
```

이 기능을 **타입 추론(Type Inference)**이라고 한다.

타입 추론 덕분에 모든 변수에 타입을 직접 작성할 필요는 없다.

---

**2. 변수의 타입 추론**

변수는 보통 초기값을 기준으로 타입이 추론된다.

```ts
let num = 10;
let message = "hello";

let user = {
  id: 1,
  name: "이정환",
};
```

추론 결과:

```text
num
→ number

message
→ string

user
→ {
    id: number;
    name: string;
  }
```

원시 타입뿐 아니라 객체의 구조도 추론할 수 있다.

---

**3. 구조 분해 할당의 타입 추론**

객체나 배열을 구조 분해할 때도 기존 값의 타입을 이용한다.

```ts
const person = {
  name: "이정환",
  age: 27,
};

const { name, age } = person;
```

```text
name → string
age  → number
```

배열도 마찬가지다.

```ts
const [one, two, three] = [1, "hello", true];
```

각 변수의 타입도 배열 요소를 기준으로 추론된다.

---

**4. 함수 반환 타입 추론**

함수의 반환 타입은 `return` 값을 기준으로 추론할 수 있다.

```ts
function getMessage() {
  return "hello";
}
```

```text
반환 타입
→ string
```

따라서 반환 타입이 명확한 경우에는 항상 직접 작성할 필요는 없다.

---

**5. 기본값이 있는 매개변수**

함수 매개변수에 기본값이 있다면 해당 값을 기준으로 타입을 추론할 수 있다.

```ts
function printMessage(message = "hello") {
  console.log(message);
}
```

```text
message
→ string
```

반면 아무 정보도 없는 매개변수는 타입을 판단하기 어렵다.

```ts
function func(param) {}
```

엄격한 설정에서는 이런 **암시적 `any`**를 오류로 처리할 수 있으므로 매개변수 타입을 명시해야 한다.

```ts
function func(param: number) {}
```

---

**6. 초기값이 없는 변수와 any의 진화**

초기값 없이 선언한 변수는 이후 코드 흐름에서 할당된 값을 기준으로 타입이 좁혀질 수 있다.

```ts
let value;

value = 10;
value.toFixed();

value = "hello";
value.toUpperCase();
```

```text
value = 10
→ 현재 흐름에서 number

value = "hello"
→ 현재 흐름에서 string
```

이러한 동작을 강의에서는 **any의 진화**라고 설명한다.

즉, TypeScript가 코드 흐름을 분석해서 현재 시점의 값을 더 구체적인 타입으로 판단한다.

---

**7. let과 const의 타입 추론**

`let`과 `const`는 값 변경 가능 여부가 다르기 때문에 타입 추론 결과도 달라질 수 있다.

```ts
let num1 = 10;
const num2 = 10;
```

```text
num1 → number
num2 → 10
```

문자열도 같다.

```ts
let str1 = "hello";
const str2 = "hello";
```

```text
str1 → string
str2 → "hello"
```

`let`은 값이 변경될 수 있으므로 더 넓은 타입으로 추론된다.

`const`로 선언한 원시 값은 변경할 수 없으므로 리터럴 타입으로 더 좁게 추론될 수 있다.

---

**8. 최적 공통 타입**

여러 타입의 값이 함께 있는 배열도 TypeScript가 적절한 타입을 추론한다.

```ts
const arr = [1, "hello"];
```

숫자와 문자열을 모두 저장해야 하므로 다음과 같은 타입으로 추론된다.

```ts
(number | string)[]
```

```text
number
+
string
↓
두 타입을 모두 포함할 수 있는 타입
↓
number | string
```

여러 값의 타입을 고려해 가장 적절한 공통 타입을 찾는 방식을 **최적 공통 타입(Best Common Type)**이라고 한다.

---

**9. 타입 추론을 사용하는 기준**

타입을 명확하게 추론할 수 있다면 굳이 중복해서 작성할 필요는 없다.

```ts
const name = "이정환";
```

다음처럼 작성해도 되지만 타입 정보가 중복된다.

```ts
const name: string = "이정환";
```

반면 함수 매개변수처럼 TypeScript가 타입을 판단할 정보가 부족하다면 직접 타입을 작성해야 한다.

```text
추론 가능
→ TypeScript에 맡길 수 있음

추론 정보 부족
→ 타입 직접 작성
```

---

**10. 핵심 정리**

* 타입 추론은 TypeScript가 타입을 자동으로 판단하는 기능이다.
* 변수는 주로 초기값을 기준으로 타입을 추론한다.
* 객체와 구조 분해 할당에서도 타입을 추론한다.
* 함수 반환 타입은 `return` 값을 기준으로 추론할 수 있다.
* 기본값이 있는 매개변수도 기본값을 기준으로 타입이 추론된다.
* 타입 정보가 없는 함수 매개변수는 암시적 `any` 문제가 발생할 수 있다.
* 초기값 없이 선언한 변수는 코드 흐름에 따라 할당된 값의 타입으로 좁혀질 수 있다.
* `let`은 보통 넓은 타입, `const`의 원시 값은 리터럴 타입으로 추론될 수 있다.
* 여러 타입의 값을 가진 배열은 공통으로 표현할 수 있는 타입을 추론한다.
* 핵심은 **명확하게 추론되는 타입은 TypeScript에 맡기고, 추론할 정보가 부족한 곳은 직접 타입을 작성하는 것**이다.
