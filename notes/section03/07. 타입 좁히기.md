# Section 3 - 7. 타입 좁히기

**1. 타입 좁히기란?**

타입 좁히기는 **넓은 타입을 조건문 안에서 더 구체적인 타입으로 판단하는 것**이다.

예:

```ts
function func(value: number | string) {}
```

`value`는 `number`일 수도 있고 `string`일 수도 있다.

따라서 바로 특정 타입의 메서드를 사용할 수는 없다.

```ts
value.toFixed();
value.toUpperCase();
```

---

**2. typeof로 좁히기**

원시 타입은 `typeof`를 이용해 좁힐 수 있다.

```ts
function func(value: number | string) {
  if (typeof value === "number") {
    value.toFixed();
  }

  if (typeof value === "string") {
    value.toUpperCase();
  }
}
```

조건문 안에서는 타입이 다음처럼 좁혀진다.

```text
number | string
↓
number
```

또는

```text
number | string
↓
string
```

---

**3. 타입 가드**

타입을 좁히기 위해 사용하는 조건을 **타입 가드(Type Guard)**라고 한다.

```ts
if (typeof value === "number") {
  // value: number
}
```

```text
타입 가드
→ 값의 타입 확인
→ 조건문 안에서 타입 좁히기
→ 해당 타입의 기능을 안전하게 사용
```

---

**4. instanceof로 좁히기**

클래스 인스턴스는 `instanceof`로 확인할 수 있다.

```ts
function func(value: number | string | Date) {
  if (value instanceof Date) {
    value.getTime();
  }
}
```

```text
number | string | Date
↓
Date
```

`instanceof`는 JavaScript 실행 시 실제로 존재하는 클래스를 대상으로 사용한다.

예:

```text
Date
Array
직접 만든 class
```

---

**5. 타입 별칭에는 instanceof를 사용할 수 없다**

다음 `Person`은 TypeScript의 타입 별칭이다.

```ts
type Person = {
  name: string;
  age: number;
};
```

따라서 다음 코드는 사용할 수 없다.

```ts
value instanceof Person;
```

`Person`은 컴파일되면 사라지기 때문에 런타임에서 확인할 대상이 없기 때문이다.

---

**6. in으로 객체 타입 좁히기**

객체가 특정 프로퍼티를 가지고 있는지 확인하려면 `in` 연산자를 사용할 수 있다.

```ts
type Person = {
  name: string;
  age: number;
};
```

예:

```ts
function func(
  value: number | string | Date | Person
) {
  if (
    typeof value === "object" &&
    value !== null &&
    "name" in value
  ) {
    console.log(value.name);
  }
}
```

`Person`에만 `name` 프로퍼티가 있다면 조건문 안에서 `Person`으로 좁혀질 수 있다.

---

**7. 객체 여부와 null을 함께 확인하는 이유**

`in`은 객체를 대상으로 사용해야 한다.

따라서 먼저 객체인지 확인한다.

```ts
typeof value === "object"
```

하지만 JavaScript에는 다음 특징이 있다.

```ts
typeof null;
```

결과:

```text
"object"
```

따라서 `null`도 따로 제외해야 한다.

```ts
typeof value === "object" &&
value !== null
```

그 후 원하는 프로퍼티를 확인한다.

```ts
"name" in value
```

---

**8. 타입 가드별 용도**

```text
typeof
→ number, string, boolean 등 원시 타입 확인

instanceof
→ 클래스 인스턴스 확인

in
→ 객체에 특정 프로퍼티가 있는지 확인
```

상황에 맞는 타입 가드를 사용하면 된다.

---

**9. 전체 예제**

```ts
type Person = {
  name: string;
  age: number;
};

function func(
  value: number | string | Date | Person
) {
  if (typeof value === "number") {
    console.log(value.toFixed());
  }

  if (typeof value === "string") {
    console.log(value.toUpperCase());
  }

  if (value instanceof Date) {
    console.log(value.getTime());
  }

  if (
    typeof value === "object" &&
    value !== null &&
    "name" in value
  ) {
    console.log(
      `${value.name}은 ${value.age}살입니다.`
    );
  }
}
```

---

**10. 전체 흐름**

```text
value
: number | string | Date | Person

typeof === "number"
→ number

typeof === "string"
→ string

instanceof Date
→ Date

"name" in value
→ Person
```

---

**11. 핵심 정리**

* 타입 좁히기는 넓은 타입을 더 구체적인 타입으로 판단하는 과정이다.
* Union 타입에서는 특정 타입 전용 메서드를 바로 사용할 수 없다.
* 조건문으로 타입을 확인하면 해당 블록 안에서 타입이 좁혀진다.
* 이러한 조건을 **타입 가드**라고 한다.
* `typeof`는 주로 원시 타입을 좁힐 때 사용한다.
* `instanceof`는 클래스 인스턴스를 좁힐 때 사용한다.
* 타입 별칭은 런타임에 존재하지 않으므로 `instanceof`에 사용할 수 없다.
* `in`은 객체의 특정 프로퍼티 존재 여부를 확인할 때 사용한다.
* 객체를 `in`으로 검사하기 전에는 객체 여부와 `null` 여부를 함께 확인해야 할 수 있다.
* 핵심은 **`넓은 타입 → 타입 가드 → 구체적인 타입`** 흐름이다.
