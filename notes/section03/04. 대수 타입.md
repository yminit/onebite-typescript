# Section 3 - 4. 대수 타입

**1. 대수 타입이란?**

대수 타입은 **여러 타입을 조합해서 새로운 타입을 만드는 방식**이다.

대표적으로 두 가지가 있다.

```text
Union 타입
→ 합집합
→ |

Intersection 타입
→ 교집합
→ &
```

---

**2. Union 타입**

Union 타입은 **여러 타입 중 하나를 만족하면 되는 타입**이다.

```ts
let value: string | number;
```

이 변수에는 문자열이나 숫자를 저장할 수 있다.

```ts
value = "hello";
value = 10;
```

타입을 더 추가할 수도 있다.

```ts
let value: string | number | boolean;
```

---

**3. Union 타입과 배열**

여러 타입의 값을 하나의 배열에 넣고 싶다면 다음처럼 작성한다.

```ts
const arr: (number | string | boolean)[] = [
  1,
  "hello",
  true,
];
```

괄호 안의 Union 타입 전체가 배열 요소의 타입이다.

```text
(number | string | boolean)[]
```

---

**4. 객체의 Union 타입**

객체 타입도 Union으로 조합할 수 있다.

```ts
type Dog = {
  name: string;
  color: string;
};

type Person = {
  name: string;
  language: string;
};

type Union = Dog | Person;
```

다음 객체는 `Dog`를 만족하므로 가능하다.

```ts
const value1: Union = {
  name: "돌돌이",
  color: "brown",
};
```

다음 객체는 `Person`을 만족하므로 가능하다.

```ts
const value2: Union = {
  name: "홍길동",
  language: "ko",
};
```

두 타입을 모두 만족해도 가능하다.

```ts
const value3: Union = {
  name: "홍길동",
  color: "black",
  language: "ko",
};
```

하지만 어느 타입도 완전히 만족하지 못하면 안 된다.

```ts
const value4: Union = {
  name: "홍길동",
};
```

`Dog`에는 `color`가 부족하고, `Person`에는 `language`가 부족하다.

---

**5. Intersection 타입**

Intersection 타입은 **여러 타입을 동시에 모두 만족해야 하는 타입**이다.

```ts
type Intersection = Dog & Person;
```

`Dog`와 `Person`의 조건을 모두 만족해야 하므로 다음 프로퍼티가 필요하다.

```text
name
color
language
```

예:

```ts
const value: Intersection = {
  name: "홍길동",
  color: "black",
  language: "ko",
};
```

---

**6. 기본 타입의 Intersection**

다음 타입을 보자.

```ts
type Value = number & string;
```

`number`이면서 동시에 `string`인 값은 존재하지 않는다.

따라서 결과는 사실상 `never`가 된다.

```text
number ∩ string
↓
공통 값 없음
↓
never
```

그래서 Intersection은 객체 타입을 조합할 때 특히 자주 이해하기 쉽다.

---

**7. 객체 Union과 Intersection 비교**

```ts
type Dog = {
  name: string;
  color: string;
};

type Person = {
  name: string;
  language: string;
};
```

Union:

```ts
type Union = Dog | Person;
```

```text
Dog 또는 Person
→ 둘 중 하나 이상 만족
```

Intersection:

```ts
type Intersection = Dog & Person;
```

```text
Dog 그리고 Person
→ 둘 다 만족
```

---

**8. 집합으로 이해하기**

Union은 두 타입의 범위를 합친다.

```text
Dog ∪ Person
```

Intersection은 두 타입에 동시에 속하는 값만 남긴다.

```text
Dog ∩ Person
```

즉,

```text
Union
→ 허용 범위가 넓어짐

Intersection
→ 만족해야 하는 조건이 많아짐
```

으로 이해하면 된다.

---

**9. 핵심 코드**

```ts
let value: string | number | boolean;

value = "hello";
value = 10;
value = true;

const arr: (number | string | boolean)[] = [
  1,
  "hello",
  true,
];

type Dog = {
  name: string;
  color: string;
};

type Person = {
  name: string;
  language: string;
};

type Union = Dog | Person;

const union1: Union = {
  name: "돌돌이",
  color: "brown",
};

const union2: Union = {
  name: "홍길동",
  language: "ko",
};

type Intersection = Dog & Person;

const intersection: Intersection = {
  name: "홍길동",
  color: "black",
  language: "ko",
};
```

---

**10. 핵심 정리**

* 대수 타입은 여러 타입을 조합해서 만든 타입이다.
* `|`는 Union 타입이다.
* Union은 **여러 타입 중 하나 이상을 만족하면 된다.**
* `(number | string)[]`처럼 배열 요소 타입에도 사용할 수 있다.
* `&`는 Intersection 타입이다.
* Intersection은 **여러 타입을 동시에 모두 만족해야 한다.**
* `number & string`처럼 공통 값이 없는 타입의 교집합은 `never`가 될 수 있다.
* 객체에서는 `Dog | Person`은 둘 중 하나 이상, `Dog & Person`은 둘 다 만족해야 한다.
* 핵심은 **`| = 또는`, `& = 그리고`**로 이해하면 된다.
