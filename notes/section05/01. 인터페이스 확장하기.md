# Section 5 - 1. 인터페이스 확장하기

**1. 인터페이스 확장이란?**

인터페이스 확장은 **기존 인터페이스의 구조를 다른 인터페이스가 물려받는 문법**이다.

`extends` 키워드를 사용한다.

```ts
interface Animal {
  name: string;
  age: number;
}

interface Dog extends Animal {
  isBark: boolean;
}
```

`Dog`는 `Animal`의 프로퍼티를 모두 포함한다.

```text
Dog
├─ name
├─ age
└─ isBark
```

---

**2. 왜 확장을 사용할까?**

공통 프로퍼티를 여러 인터페이스에 반복해서 작성하면 중복이 생긴다.

```ts
interface Dog {
  name: string;
  age: number;
  isBark: boolean;
}

interface Cat {
  name: string;
  age: number;
  isScratch: boolean;
}
```

공통 부분을 `Animal`로 분리하면 중복을 줄일 수 있다.

```ts
interface Animal {
  name: string;
  age: number;
}

interface Dog extends Animal {
  isBark: boolean;
}

interface Cat extends Animal {
  isScratch: boolean;
}
```

```text
공통 구조
→ Animal

개별 구조
→ Dog
→ Cat
```

---

**3. 확장한 인터페이스 사용하기**

```ts
interface Animal {
  name: string;
  age: number;
}

interface Dog extends Animal {
  isBark: boolean;
}

const dog: Dog = {
  name: "돌돌이",
  age: 3,
  isBark: true,
};
```

`Dog` 타입의 객체는 `Animal`에서 물려받은 프로퍼티와 자신이 추가한 프로퍼티를 모두 가져야 한다.

---

**4. 슈퍼 타입과 서브 타입 관계**

`Dog extends Animal`이면 `Dog`는 `Animal`의 모든 조건을 만족한다.

```text
Animal
  ↑
 Dog
```

따라서:

```text
Animal
→ 슈퍼 타입

Dog
→ 서브 타입
```

이다.

---

**5. 프로퍼티 타입 재정의**

확장하면서 기존 프로퍼티의 타입을 더 구체적으로 재정의할 수도 있다.

```ts
interface Animal {
  name: string;
  age: number;
}

interface Dog extends Animal {
  name: "doldol";
  isBark: boolean;
}
```

`Dog`의 `name`은 이제 `"doldol"`만 허용한다.

```text
string
  ↑
"doldol"
```

즉, 원래 타입보다 더 좁은 타입으로 재정의할 수 있다.

---

**6. 호환되지 않는 타입으로는 재정의할 수 없다**

다음은 불가능하다.

```ts
interface Animal {
  name: string;
}

interface Dog extends Animal {
  name: number;
}
```

`Dog`는 `Animal`의 서브 타입이어야 하는데, `number`는 `string`의 조건을 만족하지 않는다.

```text
Animal
name: string

Dog
name: number

→ Animal의 구조를 만족하지 못함
```

---

**7. 타입 별칭으로 만든 객체 타입도 확장 가능**

인터페이스는 다른 인터페이스뿐 아니라 **객체 형태의 타입 별칭**도 확장할 수 있다.

```ts
type Animal = {
  name: string;
  age: number;
};

interface Dog extends Animal {
  isBark: boolean;
}
```

결과적으로 `Dog`는 다음 구조를 가진다.

```text
name
age
isBark
```

---

**8. 여러 인터페이스 동시에 확장하기**

하나의 인터페이스가 여러 인터페이스를 동시에 확장할 수도 있다.

```ts
interface Dog {
  name: string;
  isBark: boolean;
}

interface Cat {
  name: string;
  isScratch: boolean;
}

interface DogCat extends Dog, Cat {}
```

`DogCat`은 두 인터페이스의 프로퍼티를 모두 가진다.

```text
DogCat
├─ name
├─ isBark
└─ isScratch
```

사용:

```ts
const dogCat: DogCat = {
  name: "개냥이",
  isBark: true,
  isScratch: true,
};
```

---

**9. 핵심 구조**

```text
기존 인터페이스
↓ extends
확장 인터페이스
↓
기존 프로퍼티 상속
+
새로운 프로퍼티 추가
```

예:

```ts
interface Animal {
  name: string;
  age: number;
}

interface Dog extends Animal {
  isBark: boolean;
}
```

---

**10. 전체 예제**

```ts
interface Animal {
  name: string;
  age: number;
}

interface Dog extends Animal {
  isBark: boolean;
}

interface Cat extends Animal {
  isScratch: boolean;
}

interface Chicken extends Animal {
  isFly: boolean;
}

const dog: Dog = {
  name: "돌돌이",
  age: 3,
  isBark: true,
};
```

다중 확장:

```ts
interface BarkAnimal {
  name: string;
  isBark: boolean;
}

interface ScratchAnimal {
  name: string;
  isScratch: boolean;
}

interface DogCat extends BarkAnimal, ScratchAnimal {}

const dogCat: DogCat = {
  name: "개냥이",
  isBark: true,
  isScratch: true,
};
```

---

**11. 핵심 정리**

* 인터페이스 확장은 기존 인터페이스의 구조를 물려받는 문법이다.
* `extends` 키워드를 사용한다.
* 공통 프로퍼티 중복을 줄이고 유지보수를 쉽게 만들 수 있다.
* `Dog extends Animal`이면 `Dog`는 `Animal`의 서브 타입이 된다.
* 확장하면서 기존 프로퍼티를 더 좁은 타입으로 재정의할 수 있다.
* 원본 타입과 호환되지 않는 타입으로는 재정의할 수 없다.
* 인터페이스는 객체 형태의 타입 별칭도 확장할 수 있다.
* 여러 인터페이스를 동시에 확장할 수도 있다.
* 핵심은 **`공통 구조를 부모 인터페이스로 분리하고, 개별 인터페이스가 extends로 재사용하는 것`**이다.
