# Section 4 - 3. 함수 오버로딩

**1. 함수 오버로딩이란?**

함수 오버로딩은 **하나의 함수를 여러 호출 형태로 사용할 수 있게 정의하는 방법**이다.

예:

```text
func(1)
func(1, 2, 3)
```

같은 함수 이름을 사용하지만 전달하는 매개변수의 개수나 타입에 따라 다른 형태로 호출할 수 있다.

---

**2. 오버로드 시그니처**

함수가 어떤 형태로 호출될 수 있는지 먼저 선언한다.

```ts
function func(a: number): void;

function func(
  a: number,
  b: number,
  c: number
): void;
```

이처럼 **구현부 없이 선언만 작성한 함수 타입**을 오버로드 시그니처라고 한다.

```text
func
├─ number 1개
└─ number 3개
```

---

**3. 구현 시그니처**

오버로드 시그니처 아래에는 실제 동작을 구현하는 함수가 필요하다.

```ts
function func(
  a: number,
  b?: number,
  c?: number
) {
  if (
    typeof b === "number" &&
    typeof c === "number"
  ) {
    console.log(a + b + c);
  } else {
    console.log(a * 20);
  }
}
```

이를 **구현 시그니처**라고 한다.

```text
오버로드 시그니처
→ 호출 가능한 형태 정의

구현 시그니처
→ 실제 실행 로직 정의
```

---

**4. 구현 시그니처는 모든 오버로드를 처리해야 한다**

현재 함수는 다음 두 형태를 지원한다.

```text
func(number)

func(number, number, number)
```

따라서 구현에서는 `b`, `c`가 없을 수도 있어야 한다.

```ts
function func(
  a: number,
  b?: number,
  c?: number
) {}
```

만약 모두 필수로 작성하면:

```ts
function func(
  a: number,
  b: number,
  c: number
) {}
```

매개변수 하나만 받는 오버로드를 처리할 수 없게 된다.

---

**5. 실제 함수 호출은 오버로드 시그니처 기준**

허용되는 호출:

```ts
func(1);
func(1, 2, 3);
```

허용되지 않는 호출:

```ts
func();
func(1, 2);
func(1, 2, 3, 4);
```

중요한 점은 구현 시그니처에 `b?`, `c?`가 있어도 다음 호출이 허용되는 것은 아니라는 것이다.

```ts
func(1, 2);
```

호출 가능 여부는 **구현 시그니처가 아니라 오버로드 시그니처를 기준으로 판단한다.**

---

**6. 호출에 따른 동작**

매개변수 하나:

```ts
func(1);
```

```text
a → 1
b → undefined
c → undefined
```

따라서:

```ts
console.log(a * 20);
```

이 실행된다.

매개변수 세 개:

```ts
func(1, 2, 3);
```

```text
a → 1
b → 2
c → 3
```

따라서:

```ts
console.log(a + b + c);
```

가 실행된다.

---

**7. 전체 구조**

```ts
// 오버로드 시그니처
function func(a: number): void;

function func(
  a: number,
  b: number,
  c: number
): void;

// 구현 시그니처
function func(
  a: number,
  b?: number,
  c?: number
) {
  if (
    typeof b === "number" &&
    typeof c === "number"
  ) {
    console.log(a + b + c);
  } else {
    console.log(a * 20);
  }
}

func(1);
func(1, 2, 3);
```

---

**8. 핵심 흐름**

```text
오버로드 시그니처 작성
↓
호출 가능한 함수 형태 정의
↓
구현 시그니처 작성
↓
모든 오버로드를 하나의 함수에서 처리
```

---

**9. 핵심 정리**

* 함수 오버로딩은 하나의 함수를 여러 형태로 호출할 수 있게 만든다.
* 구현부 없이 함수 형태만 선언한 것을 **오버로드 시그니처**라고 한다.
* 실제 실행 로직을 작성한 함수를 **구현 시그니처**라고 한다.
* 구현 시그니처는 모든 오버로드 시그니처를 처리할 수 있어야 한다.
* 매개변수 개수가 다른 오버로드를 처리하기 위해 선택적 매개변수를 사용할 수 있다.
* 실제 호출 가능 여부는 구현 시그니처가 아니라 **오버로드 시그니처를 기준으로 검사한다.**
* 핵심은 **`여러 호출 형태를 선언하고, 실제 구현은 하나의 함수에서 처리하는 것`**이다.
