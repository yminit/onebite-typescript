# Section 4 - 0. 함수 타입

**1. 함수 타입의 핵심**

함수의 타입은 크게 두 가지로 결정된다.

```text
매개변수 타입
+
반환값 타입
```

예:

```ts
function add(a: number, b: number): number {
  return a + b;
}
```

```text
a: number
b: number
→ 매개변수 타입

: number
→ 반환값 타입
```

---

**2. 매개변수 타입**

각 매개변수에 타입을 지정할 수 있다.

```ts
function add(a: number, b: number) {
  return a + b;
}
```

올바른 호출:

```ts
add(1, 2);
```

잘못된 호출:

```ts
add("1", "2");
```

매개변수 타입과 다른 값을 전달하면 오류가 발생한다.

---

**3. 반환값 타입**

함수의 반환 타입은 매개변수 뒤에 작성한다.

```ts
function add(a: number, b: number): number {
  return a + b;
}
```

반환 타입과 실제 반환값이 다르면 오류가 발생한다.

```ts
function add(a: number, b: number): number {
  return "hello";
}
```

---

**4. 반환 타입은 추론할 수 있다**

TypeScript는 `return` 값을 보고 반환 타입을 추론할 수 있다.

```ts
function add(a: number, b: number) {
  return a + b;
}
```

```text
반환 타입
→ number
```

따라서 반환 타입이 명확하다면 생략할 수 있다.

---

**5. 화살표 함수**

화살표 함수도 같은 방식으로 타입을 작성한다.

```ts
const add = (a: number, b: number): number => {
  return a + b;
};
```

반환 타입은 생략할 수도 있다.

```ts
const add = (a: number, b: number) => {
  return a + b;
};
```

---

**6. 기본값이 있는 매개변수**

기본값이 있다면 해당 값을 기준으로 타입이 추론된다.

```ts
function introduce(name = "이정환") {
  console.log(name);
}
```

```text
name
→ string
```

타입을 직접 작성할 수도 있다.

```ts
function introduce(name: string = "이정환") {
  console.log(name);
}
```

타입과 기본값의 타입은 서로 맞아야 한다.

---

**7. 선택적 매개변수**

생략 가능한 매개변수는 `?`를 사용한다.

```ts
function introduce(
  name: string,
  tall?: number
) {}
```

호출:

```ts
introduce("이정환");
introduce("이정환", 175);
```

선택적 매개변수는 값이 없을 수 있으므로 사실상 다음처럼 다뤄진다.

```text
tall?: number

→ number | undefined
```

따라서 사용할 때 타입 좁히기가 필요할 수 있다.

```ts
function introduce(
  name: string,
  tall?: number
) {
  if (typeof tall === "number") {
    console.log(tall + 10);
  }
}
```

---

**8. 선택적 매개변수의 위치**

선택적 매개변수는 필수 매개변수 뒤에 작성해야 한다.

잘못된 형태:

```ts
function func(a?: string, b: number) {}
```

올바른 형태:

```ts
function func(a: string, b?: number) {}
```

```text
필수 매개변수
→ 선택적 매개변수
```

---

**9. 나머지 매개변수**

나머지 매개변수는 여러 인수를 배열로 받는다.

```ts
function getSum(...rest: number[]) {
  let sum = 0;

  rest.forEach((item) => {
    sum += item;
  });

  return sum;
}
```

호출:

```ts
getSum(1, 2, 3);
getSum(1, 2, 3, 4, 5);
```

```text
...rest
→ 여러 인수 수집

rest: number[]
→ 숫자 배열
```

---

**10. 나머지 매개변수의 길이 고정**

튜플을 사용하면 인수 개수까지 고정할 수 있다.

```ts
function getFixedSum(
  ...rest: [number, number, number]
) {
  return rest[0] + rest[1] + rest[2];
}
```

올바른 호출:

```ts
getFixedSum(1, 2, 3);
```

다음은 오류가 발생한다.

```ts
getFixedSum(1, 2);
getFixedSum(1, 2, 3, 4);
```

---

**11. 핵심 코드**

```ts
function add(a: number, b: number) {
  return a + b;
}

const addArrow = (
  a: number,
  b: number
) => {
  return a + b;
};

function introduce(
  name = "이정환",
  tall?: number
) {
  console.log(`name: ${name}`);

  if (typeof tall === "number") {
    console.log(`tall: ${tall + 10}`);
  }
}

function getSum(...rest: number[]) {
  let sum = 0;

  rest.forEach((item) => {
    sum += item;
  });

  return sum;
}

function getFixedSum(
  ...rest: [number, number, number]
) {
  return rest[0] + rest[1] + rest[2];
}
```

---

**12. 핵심 정리**

* 함수 타입은 **매개변수 타입 + 반환값 타입**으로 결정된다.
* 매개변수에는 각각 타입을 지정한다.
* 반환 타입은 직접 작성할 수도 있고 `return` 값으로 추론할 수도 있다.
* 화살표 함수도 같은 방식으로 타입을 정의한다.
* 기본값이 있는 매개변수는 기본값을 기준으로 타입을 추론할 수 있다.
* `?`를 사용하면 선택적 매개변수가 된다.
* 선택적 매개변수는 `undefined`일 수 있으므로 타입 좁히기가 필요할 수 있다.
* 선택적 매개변수는 필수 매개변수 뒤에 작성한다.
* 나머지 매개변수는 `...rest: number[]`처럼 배열 타입으로 정의한다.
* 튜플을 사용하면 나머지 매개변수의 개수까지 제한할 수 있다.
* 핵심은 **함수가 어떤 값을 받고, 어떤 값을 반환하는지를 타입으로 표현하는 것**이다.
