# Section 4 - 1. 함수 타입 표현식과 호출 시그니처

**1. 함수 타입을 별도로 정의하기**

함수의 타입을 함수 구현과 분리해서 따로 정의할 수 있다.

대표적인 방법은 두 가지이다.

```text
함수 타입 표현식
호출 시그니처
```

둘 다 **매개변수 타입과 반환값 타입을 하나의 타입으로 표현**하는 방법이다.

---

**2. 함수 타입 표현식**

함수 타입 표현식(Function Type Expression)은 화살표 함수와 비슷한 형태로 작성한다.

```ts
type Operation = (a: number, b: number) => number;
```

의미:

```text
a: number
b: number
→ 반환값: number
```

기본 형태:

```ts
type 타입이름 = (매개변수: 타입) => 반환타입;
```

---

**3. 함수 타입 표현식 사용하기**

정의한 타입을 함수 변수에 적용할 수 있다.

```ts
type Operation = (a: number, b: number) => number;

const add: Operation = (a, b) => a + b;
```

`a`, `b`, 반환값의 타입은 `Operation`을 통해 결정되므로 함수 구현에서 다시 작성하지 않아도 된다.

---

**4. 같은 형태의 함수 재사용**

여러 함수가 같은 구조를 가진다면 타입을 한 번만 정의해서 재사용할 수 있다.

```ts
type Operation = (a: number, b: number) => number;

const add: Operation = (a, b) => a + b;
const sub: Operation = (a, b) => a - b;
const multiply: Operation = (a, b) => a * b;
const divide: Operation = (a, b) => a / b;
```

```text
함수 타입 한 번 정의
→ 여러 함수에서 재사용
→ 중복 감소
```

---

**5. 타입 별칭 없이 직접 작성하기**

함수 타입 표현식을 변수 타입에 바로 작성할 수도 있다.

```ts
const add: (a: number, b: number) => number = (
  a,
  b
) => {
  return a + b;
};
```

한 번만 사용할 타입이라면 가능하지만, 반복해서 사용한다면 타입 별칭으로 분리하는 편이 읽기 쉽다.

---

**6. 호출 시그니처**

호출 시그니처(Call Signature)는 객체 타입과 비슷한 형태로 함수의 호출 구조를 정의한다.

```ts
type Operation = {
  (a: number, b: number): number;
};
```

기본 형태:

```ts
type 타입이름 = {
  (매개변수: 타입): 반환타입;
};
```

사용:

```ts
const add: Operation = (a, b) => a + b;
```

---

**7. 두 문법의 차이**

함수 타입 표현식:

```ts
type Operation = (a: number, b: number) => number;
```

호출 시그니처:

```ts
type Operation = {
  (a: number, b: number): number;
};
```

둘 다 같은 형태의 함수를 표현할 수 있다.

```text
함수 타입 표현식
→ 간단한 함수 타입 표현에 적합

호출 시그니처
→ 함수에 추가 프로퍼티까지 표현할 때 유용
```

---

**8. 함수도 객체이다**

JavaScript의 함수는 호출할 수 있는 값이면서 동시에 객체이기도 하다.

```ts
function func() {}

func();
func.name;
```

따라서 TypeScript에서도 **호출 가능한 구조와 객체 프로퍼티를 함께 가진 타입**을 표현할 수 있다.

---

**9. 하이브리드 타입**

호출 시그니처에 프로퍼티를 추가할 수 있다.

```ts
type HybridOperation = {
  (a: number, b: number): number;
  description: string;
};
```

이 타입의 값은 두 조건을 모두 만족해야 한다.

```text
함수처럼 호출 가능
+
description 프로퍼티 보유
```

예:

```ts
const add = ((a: number, b: number) => {
  return a + b;
}) as HybridOperation;

add.description = "두 숫자를 더합니다.";
```

이처럼 **함수이면서 객체 프로퍼티도 가진 타입**을 하이브리드 타입이라고 한다.

---

**10. 핵심 구조**

```text
함수 타입 표현식

(a: number, b: number) => number
```

```text
호출 시그니처

{
  (a: number, b: number): number;
}
```

```text
하이브리드 타입

{
  (a: number, b: number): number;
  description: string;
}
```

---

**11. 핵심 정리**

* 함수 타입 표현식은 함수 타입을 별도로 정의하는 방법이다.
* `(매개변수: 타입) => 반환타입` 형태로 작성한다.
* 같은 구조의 함수가 여러 개라면 타입을 재사용할 수 있다.
* 함수 구현과 타입 선언을 분리할 수 있다.
* 호출 시그니처도 함수 타입을 정의하는 방법이다.
* 호출 시그니처는 `{ (매개변수): 반환타입 }` 형태로 작성한다.
* 단순한 함수 타입은 함수 타입 표현식이 더 간단하다.
* 호출 시그니처는 함수에 프로퍼티까지 함께 표현할 수 있다.
* 함수처럼 호출되면서 객체 프로퍼티도 가지는 타입을 하이브리드 타입이라고 한다.
* 핵심은 **`함수 타입 표현식 = 간단한 함수 구조`, `호출 시그니처 = 호출 구조 + 객체 프로퍼티 표현 가능`**이다.
