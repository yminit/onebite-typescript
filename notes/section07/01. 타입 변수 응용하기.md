# Section 7 - 1. 타입 변수 응용하기

**1. 타입 변수는 여러 개 사용할 수 있다**

제네릭 함수에는 타입 변수를 여러 개 선언할 수 있다.

```ts
function swap<T, U>(a: T, b: U) {
  return [b, a];
}
```

사용:

```ts
const [a, b] = swap("1", 2);
```

추론 결과:

```text
T → string
U → number
```

즉, 각 인수의 타입을 서로 독립적으로 추론할 수 있다.

---

**2. 배열의 요소 타입을 제네릭으로 받기**

다양한 배열을 받으려면 `T[]`를 사용할 수 있다.

```ts
function returnFirstValue<T>(data: T[]) {
  return data[0];
}
```

숫자 배열:

```ts
const num = returnFirstValue([0, 1, 2]);
```

```text
T → number
반환값 → number
```

여러 타입이 섞인 배열:

```ts
const value = returnFirstValue([
  1,
  "hello",
  "mynameis",
]);
```

이 경우 배열 요소 전체를 기준으로 타입이 추론된다.

```text
T → string | number

반환값
→ string | number
```

실제 첫 번째 값은 숫자지만, 함수 타입만 보면 배열의 어떤 요소 타입이 올지 기준으로 추론하기 때문이다.

---

**3. 첫 번째 요소 타입만 정확히 얻기**

첫 번째 요소의 타입만 반환 타입으로 사용하고 싶다면 튜플을 활용할 수 있다.

```ts
function returnFirstValue<T>(
  data: [T, ...unknown[]]
) {
  return data[0];
}
```

구조:

```text
[T, ...unknown[]]

T
→ 첫 번째 요소 타입

...unknown[]
→ 두 번째 이후 요소
```

사용:

```ts
const value = returnFirstValue([
  1,
  "hello",
  "mynameis",
]);
```

추론:

```text
첫 번째 요소 → number
T → number
반환값 → number
```

나머지 요소의 타입은 `T`를 결정하는 데 사용되지 않는다.

---

**4. T[]와 튜플 방식의 차이**

일반 배열:

```ts
function returnFirstValue<T>(data: T[]) {
  return data[0];
}
```

```text
[1, "hello"]

T
→ number | string
```

첫 번째 요소를 지정한 튜플:

```ts
function returnFirstValue<T>(
  data: [T, ...unknown[]]
) {
  return data[0];
}
```

```text
[1, "hello"]

T
→ number
```

핵심은 **어떤 위치의 타입 정보를 `T`와 연결할 것인지**이다.

---

**5. 타입 변수 제한하기**

제네릭이라고 해서 모든 타입을 반드시 허용해야 하는 것은 아니다.

`extends`를 사용하면 타입 변수의 범위를 제한할 수 있다.

```ts
function getLength<
  T extends { length: number }
>(data: T) {
  return data.length;
}
```

`T`는 반드시 다음 구조를 만족해야 한다.

```ts
{
  length: number;
}
```

---

**6. 제네릭의 extends 의미**

```ts
T extends { length: number }
```

여기서 `extends`는 클래스 상속이라기보다 **제네릭 제약 조건(Generic Constraint)**을 의미한다.

```text
T는 아무 타입이나 가능
X

T는 length: number를 가진 타입만 가능
O
```

함수 내부에서는 `length`가 반드시 존재한다고 보장된다.

```ts
return data.length;
```

---

**7. length를 가진 값은 사용할 수 있다**

문자열:

```ts
getLength("123");
```

배열:

```ts
getLength([1, 2, 3]);
```

객체:

```ts
getLength({
  length: 10,
});
```

모두 `length: number` 조건을 만족한다.

```text
string
→ length 있음

array
→ length 있음

{ length: number }
→ length 있음
```

---

**8. 조건을 만족하지 않으면 사용할 수 없다**

다음 값에는 `length`가 없다.

```ts
getLength(undefined);
getLength(null);
```

따라서 제네릭 제약 조건을 만족하지 못한다.

```text
undefined
null
↓
length 없음
↓
전달 불가
```

---

**9. 제네릭 제약의 핵심**

제네릭은 타입을 유연하게 만들지만, 함수 내부에서 필요한 기능이 있다면 최소 조건을 지정해야 한다.

```ts
function getLength<
  T extends { length: number }
>(data: T) {
  return data.length;
}
```

이 함수의 의도는 다음과 같다.

```text
어떤 타입이든 받을 수 있음
단,
length: number는 반드시 있어야 함
```

즉, **유연성과 타입 안전성을 동시에 확보하는 방법**이다.

---

**10. 전체 코드**

```ts
function swap<T, U>(a: T, b: U) {
  return [b, a];
}

const [a, b] = swap("1", 2);

function returnFirstValue1<T>(
  data: T[]
) {
  return data[0];
}

const num = returnFirstValue1([
  0,
  1,
  2,
]);

const value1 = returnFirstValue1([
  1,
  "hello",
  "mynameis",
]);

function returnFirstValue2<T>(
  data: [T, ...unknown[]]
) {
  return data[0];
}

const value2 = returnFirstValue2([
  1,
  "hello",
  "mynameis",
]);

function getLength<
  T extends { length: number }
>(data: T) {
  return data.length;
}

getLength("123");
getLength([1, 2, 3]);
getLength({ length: 1 });
```

---

**11. 핵심 정리**

* 제네릭 타입 변수는 `<T, U>`처럼 여러 개 선언할 수 있다.
* 각 타입 변수는 전달된 인수를 기준으로 독립적으로 추론된다.
* `T[]`를 사용하면 다양한 요소 타입의 배열을 받을 수 있다.
* 여러 타입이 섞인 배열에서는 `T`가 Union 타입으로 추론될 수 있다.
* `[T, ...unknown[]]`을 사용하면 첫 번째 요소의 타입만 `T`로 추론할 수 있다.
* `extends`를 사용하면 타입 변수에 들어올 수 있는 타입을 제한할 수 있다.
* `T extends { length: number }`는 `T`가 반드시 `length: number` 구조를 만족해야 한다는 뜻이다.
* 제네릭 제약을 사용하면 다양한 타입을 허용하면서도 함수 내부에서 필요한 프로퍼티를 안전하게 사용할 수 있다.
* 핵심은 **`타입 변수 여러 개`, `타입 위치 지정`, `extends로 제약` 세 가지 방식으로 제네릭을 더 정교하게 사용하는 것**이다.
