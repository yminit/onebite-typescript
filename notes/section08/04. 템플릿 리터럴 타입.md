# Section 8 - 4. 템플릿 리터럴 타입

**1. 템플릿 리터럴 타입이란?**

템플릿 리터럴 타입(Template Literal Type)은 **문자열 리터럴 타입을 조합해 특정 패턴의 문자열 타입을 만드는 기능**이다.

```text
기존 문자열 리터럴 타입
↓
문자열 패턴으로 조합
↓
새로운 문자열 리터럴 타입
```

---

**2. 문자열 리터럴 Union 타입 준비하기**

```ts
type Color =
  | "red"
  | "black"
  | "green";

type Animal =
  | "dog"
  | "cat"
  | "chicken";
```

각 타입은 여러 문자열 리터럴을 가진 Union 타입이다.

```text
Color
→ "red" | "black" | "green"

Animal
→ "dog" | "cat" | "chicken"
```

---

**3. 문자열 조합을 직접 만들면 중복이 많아진다**

색상과 동물을 조합하면 다음과 같은 타입이 필요하다.

```ts
type ColoredAnimal =
  | "red-dog"
  | "red-cat"
  | "red-chicken"
  | "black-dog"
  | "black-cat"
  | "black-chicken"
  | "green-dog"
  | "green-cat"
  | "green-chicken";
```

가능한 경우의 수를 모두 직접 작성해야 한다.

```text
Color 3개
×
Animal 3개
=
총 9개
```

종류가 늘어날수록 관리하기 어려워진다.

---

**4. 템플릿 리터럴 타입 사용하기**

같은 타입을 다음처럼 간단하게 만들 수 있다.

```ts
type ColoredAnimal =
  `${Color}-${Animal}`;
```

형태는 JavaScript의 템플릿 리터럴과 비슷하다.

```text
`${Color}-${Animal}`

→ 색상-동물
```

---

**5. Union 타입끼리 조합된다**

`Color`와 `Animal`이 각각 Union 타입이므로 가능한 모든 조합이 만들어진다.

```ts
type ColoredAnimal =
  `${Color}-${Animal}`;
```

결과:

```ts
type ColoredAnimal =
  | "red-dog"
  | "red-cat"
  | "red-chicken"
  | "black-dog"
  | "black-cat"
  | "black-chicken"
  | "green-dog"
  | "green-cat"
  | "green-chicken";
```

즉, **Union × Union의 모든 문자열 조합**이 생성된다.

---

**6. 만들어진 타입 사용하기**

정해진 패턴과 일치하는 문자열만 사용할 수 있다.

```ts
const animal1: ColoredAnimal =
  "red-dog";

const animal2: ColoredAnimal =
  "black-cat";

const animal3: ColoredAnimal =
  "green-chicken";
```

다음은 사용할 수 없다.

```ts
const animal4: ColoredAnimal =
  "yellow-dog";
```

`"yellow"`가 `Color`에 없기 때문이다.

```ts
const animal5: ColoredAnimal =
  "red-tiger";
```

`"tiger"`가 `Animal`에 없기 때문에 오류가 발생한다.

---

**7. 기존 타입이 변경되면 자동 반영된다**

`Color`에 새로운 값을 추가하면:

```ts
type Color =
  | "red"
  | "black"
  | "green"
  | "blue";
```

`ColoredAnimal`은 수정할 필요가 없다.

```ts
type ColoredAnimal =
  `${Color}-${Animal}`;
```

자동으로 다음 조합이 추가된다.

```text
"blue-dog"
"blue-cat"
"blue-chicken"
```

`Animal`이 변경되어도 같은 방식으로 새로운 조합이 자동 생성된다.

---

**8. 직접 Union을 만드는 방식과 차이**

직접 작성:

```ts
type ColoredAnimal =
  | "red-dog"
  | "red-cat"
  | "red-chicken"
  | "black-dog"
  | "black-cat"
  | "black-chicken"
  | "green-dog"
  | "green-cat"
  | "green-chicken";
```

템플릿 리터럴 타입:

```ts
type ColoredAnimal =
  `${Color}-${Animal}`;
```

두 타입은 같은 문자열을 표현하지만, 템플릿 리터럴 타입은 기존 타입을 재사용하므로 중복이 훨씬 적다.

---

**9. 실무에서는 문자열 규칙을 타입으로 만들 때 유용하다**

예를 들어 이벤트 이름처럼 일정한 규칙이 있는 문자열을 표현할 수 있다.

```ts
type EventName =
  | "click"
  | "change";

type HandlerName =
  `on-${EventName}`;
```

결과:

```ts
type HandlerName =
  | "on-click"
  | "on-change";
```

핵심은 문자열을 단순히 `string`으로 두는 대신 **허용되는 문자열 패턴 자체를 타입으로 표현할 수 있다는 것**이다.

---

**10. 전체 코드**

```ts
type Color =
  | "red"
  | "black"
  | "green";

type Animal =
  | "dog"
  | "cat"
  | "chicken";

type ColoredAnimal =
  `${Color}-${Animal}`;

const coloredAnimal1: ColoredAnimal =
  "red-dog";

const coloredAnimal2: ColoredAnimal =
  "black-cat";

const coloredAnimal3: ColoredAnimal =
  "green-chicken";
```

---

**11. 핵심 정리**

* 템플릿 리터럴 타입은 특정 패턴의 문자열 타입을 만든다.
* `` `${Type}` `` 형태로 문자열 리터럴 타입을 조합한다.
* Union 타입끼리 조합하면 가능한 모든 문자열 조합이 자동 생성된다.
* 직접 긴 Union 타입을 작성하는 중복을 줄일 수 있다.
* 기존 Union 타입에 값이 추가되면 새로운 문자열 조합도 자동으로 반영된다.
* 정의된 패턴에 포함되지 않는 문자열은 사용할 수 없다.
* 핵심은 **`템플릿 리터럴 타입 = 문자열 규칙을 타입으로 표현하는 기능`**이다.
