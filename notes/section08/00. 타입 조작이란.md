# Section 8 - 0. 타입 조작이란

**1. 타입 조작이란?**

타입 조작은 **기존 타입을 기반으로 새로운 타입을 만들어내는 기능**이다.

```text
기존 타입
↓
필요한 형태로 변환
↓
새로운 타입
```

대상은 기본 타입뿐 아니라 타입 별칭, 인터페이스 등 다양한 타입이 될 수 있다.

---

**2. 제네릭도 타입 조작의 한 종류**

앞에서 배운 제네릭도 상황에 따라 타입을 바꾸어 사용할 수 있으므로 타입 조작에 포함된다.

```ts
function identity<T>(value: T): T {
  return value;
}
```

호출할 때마다 `T`가 달라진다.

```text
identity(10)
→ T = number

identity("hello")
→ T = string
```

제네릭은 내용이 많기 때문에 이전 섹션에서 따로 학습했다.

---

**3. 이번 섹션에서 배우는 타입 조작**

이번 섹션에서는 다음 네 가지를 학습한다.

```text
타입 조작

├─ 인덱스드 액세스 타입
├─ keyof
├─ 맵드 타입
└─ 템플릿 리터럴 타입
```

조건부 타입은 다음 섹션에서 별도로 학습한다.

---

**4. 인덱스드 액세스 타입**

인덱스드 액세스 타입(Indexed Access Type)은 객체, 배열, 튜플 타입에서 **특정 부분의 타입을 꺼내오는 기능**이다.

```text
전체 타입
↓
특정 프로퍼티 또는 요소 선택
↓
해당 부분의 타입 추출
```

예를 들어:

```ts
interface User {
  id: number;
  name: string;
}

type UserName = User["name"];
```

`UserName`은 다음 타입이 된다.

```ts
string
```

---

**5. keyof**

`keyof`는 객체 타입이 가진 프로퍼티 이름들을 추출한다.

```ts
interface User {
  id: number;
  name: string;
}
```

```ts
type UserKey = keyof User;
```

결과:

```ts
"id" | "name"
```

즉:

```text
객체 프로퍼티 이름
↓
문자열 리터럴 Union 타입
```

---

**6. 맵드 타입**

맵드 타입(Mapped Type)은 기존 객체 타입의 프로퍼티를 순회하면서 새로운 객체 타입을 만든다.

```text
기존 객체 타입
↓
각 프로퍼티를 변환
↓
새로운 객체 타입
```

예를 들어 모든 프로퍼티를 선택적으로 만드는 것처럼 기존 구조를 재활용할 수 있다.

```ts
interface User {
  id: number;
  name: string;
}
```

```text
기존
id: number
name: string

↓

변환

↓

id?: number
name?: string
```

실제 문법은 이후 단계에서 자세히 다룬다.

---

**7. 템플릿 리터럴 타입**

템플릿 리터럴 타입은 문자열 리터럴 타입을 조합해서 **특정 문자열 패턴을 타입으로 표현하는 기능**이다.

```text
기존 문자열 타입
↓
문자열 패턴 조합
↓
새로운 문자열 타입
```

예:

```ts
type Color = "red" | "blue";
```

이를 기반으로 다음과 같은 문자열 타입을 만들 수 있다.

```text
"red-color"
"blue-color"
```

실제 문법은 이후 단계에서 학습한다.

---

**8. 각 타입 조작의 역할**

```text
인덱스드 액세스 타입
→ 타입의 특정 부분을 꺼냄

keyof
→ 객체의 key를 꺼냄

맵드 타입
→ 기존 객체 구조를 변환

템플릿 리터럴 타입
→ 문자열 타입을 조합
```

기능은 다르지만 공통점은 **기존 타입 정보를 재사용한다는 것**이다.

---

**9. 왜 타입 조작을 사용하는가?**

타입을 직접 반복해서 만들면 기존 타입이 변경될 때 관련 타입도 함께 수정해야 한다.

타입 조작을 이용하면 기존 타입에서 필요한 정보를 가져와 새로운 타입을 만들 수 있다.

```text
기존 타입을 직접 복사
→ 중복 증가
→ 변경 시 여러 곳 수정

기존 타입을 조작
→ 타입 재사용
→ 변경 사항 자동 반영
```

따라서 타입 간 관계를 유지하면서 중복을 줄이는 데 유용하다.

---

**10. 전체 구조**

```text
타입 조작

├─ 제네릭
│  └─ 사용할 타입을 상황에 따라 결정
│
├─ 인덱스드 액세스 타입
│  └─ 특정 프로퍼티·요소 타입 추출
│
├─ keyof
│  └─ 객체의 key 타입 추출
│
├─ 맵드 타입
│  └─ 기존 객체 타입 변환
│
├─ 템플릿 리터럴 타입
│  └─ 문자열 패턴 타입 생성
│
└─ 조건부 타입
   └─ 조건에 따라 타입 결정
```

---

**11. 핵심 정리**

* 타입 조작은 기존 타입을 이용해 새로운 타입을 만드는 기능이다.
* 제네릭도 타입을 상황에 따라 변경하므로 타입 조작의 한 종류다.
* 인덱스드 액세스 타입은 객체·배열·튜플에서 특정 부분의 타입을 추출한다.
* `keyof`는 객체 타입의 프로퍼티 이름을 Union 타입으로 만든다.
* 맵드 타입은 기존 객체 타입의 각 프로퍼티를 변환해 새로운 객체 타입을 만든다.
* 템플릿 리터럴 타입은 문자열 리터럴 타입을 조합해 새로운 문자열 타입을 만든다.
* 타입 조작의 핵심 목적은 **기존 타입 정보를 재사용해 중복을 줄이고 타입 간 관계를 유지하는 것**이다.
